## 发现并修复的问题

### Bug #1 (P022): WSL 中 pkill 导致断联 ✅ 已修复

**位置**: `scripts/verify-all-2025.sh:116-119`

**问题描述**:
WSL 环境中 `pkill -f "server"` 或 `pkill -f "granian"` 命令会导致 WSL 断开连接。

**修复方案**:
移除脚本中的 pkill 命令，改为跳过服务停止步骤。

```bash
# 修复前（会导致断联）
pkill -f "granian" 2>/dev/null || true
pkill -f "server" 2>/dev/null || true

# 修复后
log_info "跳过服务停止步骤（WSL 中 pkill 会导致断联）"
sleep 1
```

**状态**: ✅ 已修复
