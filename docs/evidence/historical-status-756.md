# 历史停牌、ST 与未知状态（#756）

本票为 [#734](https://github.com/cosmos-arc/ditto/issues/734) 的普通历史重建补齐状态消费。
范围是现有回测请求、详情、保存及导出；不新增工作面，不认证历史原始版本完整性、
投资者交易资格或真人验收。代表窗口不是三类 2014 起完整目标的替代验收。

## 产品操作与结果

在策略详情提交“历史重建”请求。在回测详情展开“请求与冻结来源”，用“逐日参与日期”
查看证券状态和当日规则。日期可用键盘选择，焦点保持在选择框；报告导出结束后按 Escape
回到“导出报告”。数量单位为股，报价和估值单位为人民币元。

| 状态 | 产品行为 |
|---|---|
| 已确认全天停牌 | 不参加选股、不成交；已有持仓保留。没有当天报价时，仅执行估值使用同证券严格过去的真实收盘价，显示原报价日期；成交量为零，原来源身份不变。 |
| ST / *ST | 不作为缺证而一律拒绝；当日状态、板块、日期决定涨跌幅、订单类型及累计买入上限，逐日说明标出 ST。 |
| 零成交 | 保留供应商的真实报价供估值，不成交、不参加当日选股；不会把零成交解释成停牌。 |
| 真缺行情 | 有交易资格但缺必要报价时，定位证券和日期并拒绝运行；不以前填行情假造可交易日。 |
| 未知状态 | 缺少同日状态或其来源时拒绝，保留错误、请求及已解析来源；不按普通证券放行。 |

停牌估值不进入复权信号历史，不增加有效行情预热数。预热按决策 cutoff 前真正可见的
原始行情计数，仍遵守行情 T+1 和原有知识日期；未来报价不可回填过去估值。
没有过去报价、仅有盘中停牌证据却没有当日报价，均保留缺证失败。

失败后补齐来源，点击“补证后沿原配置新建运行”：新运行沿用原配置及已冻结成员，
重新冻结来源并关联旧运行。旧失败记录、旧来源集合不改变；成功结果刷新、重新读取及
JSON 导出均使用保存的运行身份、逐日状态、规则和原始来源。

并入同日状态的正证据。响应日期必须匹配请求，分页与既有完整性检查仍生效；不使用今天
的 `stock_basic` 覆盖过去，缺席证券不会被推定为正常。此列表不是退市清算凭证。

## 验证边界

固定系统样例通过正式 UI → API → 持久化 → 再读取，依次覆盖未知状态失败、补状态后
真缺行情失败、补报价后成功；先买入后停牌再复牌卖出，停牌和零成交日均无成交，ST
采用 5% 限幅。另有未来报价/披露哨兵、申报累计上限、跨日重置和取消释放额度检查。
系统旅程同时检查键盘、焦点、日期/单位、导出、旧身份不变及严重无障碍问题。

真人验收仍由 #779 承接。分红、拆并、退市与 ETF 退出会计、完整财务历史和三类长期
运行按 #759–#766 等后续任务完成；不因本票代表窗口通过而关闭。#720 发布安全阻断
也不由本票消除。
