# #752 逐日历史成员验收

本票交付普通历史重建请求的成员区间、上市身份冻结、实际交易日预热、逐日选股资格及持久化回读。延续 #751 的事后重建边界，不认证历史原始版本、Paper、发布或真人可用性。

## 固定样例

生产 UI → API → 引擎 → SQLite/产物 → 刷新回读路径以合成来源覆盖：缺复权时阻断、补证创建新运行、旧请求不变，晚上市证券在上市前无成交、上市后预热不足明确展示，以及成员退出、重新进入。样例中的上市日期明确为合成数据，不替代真实证券上市日期。

交易日历回归使用跨长假稀疏交易日，验证预热向前扩展至实际所需交易日；退出池的证券仍保留估值行情，缺日仍失败。空的当日合格池可产生现金目标。原价格/财务未来哨兵、来源完整性、冻结点后完成证据和 newer-empty 拒绝回退测试继续保留。
