# 股票送转的份额、成本与可卖日

对应 [#760](https://github.com/cosmos-arc/ditto/issues/760)，在 [现金分红](stock-cash-dividends-759.md) 上增加普通流通 A 股送转。成交页的“股票分红与送转账本”显示登记股数、每旧股送转比例、上市日，以及每日总份额、可卖份额、锁定份额、每股成本和总成本。金额为人民币元，份额为股；重开与导出读取保存的结果。

## 记账与拒绝边界

- 登记日收盘冻结权益；除权日增加总份额，总取得成本保持不变，每股成本相应摊薄。新份额在公告上市日前不可卖，既有份额的正常 T+1 规则独立执行。
- 新份额、可卖释放各记一次。来源重复去重，矛盾修订拒绝；账户恢复保留尚未上市的份额与事件流水。补证后新建运行，旧失败及原报告不改写。
- 成交匹配同步调整未平仓份额与成本，已实现交易保持原值。FIFO 将账户已确定的整数增股按原批次剩余份额比例归属，内部余数按大小、同余按 FIFO 顺序分配；这是成本归属，不推断市场零碎股分配。旧份额与新增锁定份额各保留摊薄后的成本及未分摊费用，新份额上市前不参与卖出匹配。匹配状态及已处理事件身份随检查点保存。
- 分派后的参考价为 `(前收盘价 − 每旧股现金) / (1 + 送转比例)`，按报价精度核对独立复权因子。停牌沿用报价也作对应调整，保留原报价日，不能作为当日可成交价格。
- 送股与资本公积转增的税基必须来自匹配本次事件的公告，不能仅凭“转增”二字假定免税。税基按登记旧股计入差别化分红税；2015-09-08 之前的初始税款先扣减应收净额，派息日才影响现金。无现金且需要初始扣税的事件也须有明确扣款日期。
- 研究账本将新增股份的取得日设为除权日，未来分红按该新批次计持有期；这是显式研究假设，未经券商逐笔税务流水核验。现有自然月/年、日终净变动、补税预留与次日扣付假设继续保留。
- 税务 FIFO 保留每批新增股份的独立上市锁定；锁定期间的合法买入、卖出不能提前消耗该批次，也不把送转锁定误计为 ST 当日买入额度。
- 无法从单一账户确定的非整数权益拒绝运行，不四舍五入造股。缺上市日、缺税务依据或日期冲突同样拒绝。配股涉及认购款和独立权益，不能传入送转比例；无法由已确认分派解释的因子变化仍阻断。

## 发行人证据与来源准备

[Tushare 分红接口](https://tushare.pro/document/2?doc_id=103) 的 `stk_bo_rate`、`stk_co_rate`、`div_listdate` 分别提供送股、转增和上市日期。`fundamental.dividend.v4` 保存这些事实及补充发行人声明；实际接收时间不回填为历史公告时间，普通重建仍不认证历史可得性。

数据源配置的 `STOCK_DISTRIBUTION_TERMS` 接受 JSON 数组，每项包含 `source_ticker`、`record_date`、`ex_date`、`listing_date`、`bonus_ratio`、`capitalization_ratio`、`taxable_share_income`、`announcement_date` 和官方 `basis_url`。先核对公告再采集；同一证券/登记日的冲突声明、晚于登记日的声明，以及与供应商非空事实不符的声明会被拒绝。仅匹配公告可补全供应商的空字段，声明内容随来源载荷保存。

普通运行按实施公告与补充公告中较晚的日期暴露事件；数据库的时点与区间查询也过滤尚未公开的补充税务事实，不借早期预案公告泄露后续声明。

例如 [浦发银行 2017-030 号官方公告](https://news.spdb.com.cn/investor_relation/company_report/201705/P020170518619025221638.pdf) 明确每股派现 0.2 元、转增 0.3 股，2017-05-24 登记、05-25 除权及派息、05-26 新股上市；公告同时说明此次股本溢价形成的资本公积转增不扣税。因此本事件的送股比例和送转税基均为零，有独立依据，不能推广到其他转增事件。

## 验收边界

固定样例通过正式页面提交、真实 API、持久化、重开及导出，覆盖缺上市日拒绝、补证重试、重复事实、延迟上市、份额/现金/净值对账及键盘焦点。账户回归另覆盖税款派发时点、同日增股与买入批次、零碎股拒绝和恢复后不重复增股。

真实供应商代表窗口、最终提交身份与 CI 结果记录在本票 PR。自动化运行不代替真人验收；本增量不关闭配股、ETF 分配、退市清算或三类 2014 起十年目标所缺的来源和会计证据。
