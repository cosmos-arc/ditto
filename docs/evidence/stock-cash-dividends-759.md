# 股票现金分红的普通历史记账

对应 [#759](https://github.com/cosmos-arc/ditto/issues/759)，属于 [#734](https://github.com/cosmos-arc/ditto/issues/734) 的会计增量。适用于个人从公开市场取得的沪深普通流通 A 股；不表示机构、限售股、ETF 或严格历史可得性已验收。

## 事实与日期

普通历史请求冻结已完成、校验通过的 `dividend` 来源载荷，保留原公告日、实施公告日、登记日、除息日、派息日、税前每股金额、送转比例、来源快照和实际接收时间。新协议是 `fundamental.dividend.v3`；缺少新增字段的旧载荷须重新采集，不猜值回填。

原公告日用于公告区间的覆盖选择；实施公告日证明最终安排的可知时间，要求早于登记日。后续修订不会改写旧报告。相同事实去重，同一除息事件的矛盾修订阻断，不能把每次公告各派一次钱。股数变化、日期或金额不明、来源覆盖缺失均阻断对应请求。

公告覆盖必须从池内最早上市日连续覆盖到请求结束；仅采集运行日期内的公告无法证明更早公告、窗口内登记的权益是否存在。已完成的空响应可以证明对应公告区间无事件，缺失区间不按空响应处理。

[Tushare 接口](https://tushare.pro/document/2?doc_id=103) 分开提供税前/税后金额、实施进度及业务日期。这里使用税前金额和显式税务模型，不把供应商税后金额用于所有持仓。复权因子只与独立现金事件核对，不能据此生成分红金额。

核对时先按报价最小单位四舍五入除息参考价，再比对复权因子；保留载荷中的因子为三位小数，允许两端各半个末位单位的取整误差。例如平安银行 2023-06-14 税前每股 0.285 元，前收盘 11.77 元，参考价为 11.49 元；不能把未取整的 11.485 元直接用于因子核对。

## 账户规则

- 登记日收盘冻结实际股数，含当天买入、排除当天卖出；除息后买入不会取得此次权益。
- 除息日增加扣除初始代扣税后的应收，从含息旧估值扣除税前分红，尚不增加可用现金。停牌沿用报价同样扣除报价日后已确认的现金分红，原报价日继续保留；信号价格通道不使用该估值。
- 派息日将应收转现金。非交易日到期在下一模拟交易时点处理，期间没有可再投资的交易时点。重复处理不重复派发。
- 日终净增股份形成取得日批次，净减按先进先出分配。税档按自然月/年周年日判断，含边界，月末不足日取该月末日。
- 同日追加成交时，从当日记账前状态重新计算最终净变化、登记与税款。未来公告不进入策略可见事件、持仓批次或账本时钟。
- 2013 年起初始代扣 5%，2015-09-08 起初始代扣 0%。卖出按持有期确定总税率，扣除已代扣部分。研究模型在卖出日预留补税，下一交易日扣付；这是模拟时点假设，不冒充券商流水。保留计算精度，不模拟逐笔分币舍入。

税制依据：[财税〔2012〕85 号](https://www.chinatax.gov.cn/chinatax/n810341/n810765/n812151/n812386/c1082457/content.html)、[财税〔2015〕101 号](https://www.chinatax.gov.cn/chinatax/n810341/n810765/n1465977/n1466017/c1967339/content.html)。自然月/年、日终净变动与先进先出依据：[证监局转载中国结算常见问答，第 10–12 问](https://www.csrc.gov.cn/shenzhen/c105614/c1575308/content.shtml)。

每日恒等式为 **净资产 = 现金 + 分红应收 + 持仓市值 − 待扣税款**。现金含预留冻结金额，可用现金已扣预留。成交页展示登记股数、税前每股金额、日期、来源、取得日批次流水及每日对账；重开与导出读取已保存结果。

分红与补税计入账户净值及分红账本，不摊入已平仓交易的价差收益或成交费用。普通历史运行仍不支持中途续跑；保存的已登记权益可在账户恢复测试中验证不重复支付。

## 验收边界

固定样例覆盖派息日缺失、补证后沿原配置新建运行、重复公告、到账前应收、现金与净值对账、重开、键盘及导出。账户与恢复测试覆盖税档日期边界、未来公告隔离和恢复后不重派。

真实供应商运行、最终提交身份与 CI 记录在本票 PR 交付评论。固定样例、真实窗口、真人验收分别判定。此增量不关闭送转/配股、ETF 分配、退市清算、三类 2014 起十年运行或真人工作面验收。
