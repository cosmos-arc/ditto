# 股票退市持仓与退出事实（#763）

本票为 [#734](https://github.com/cosmos-arc/ditto/issues/734) 的第 13 张历史研究票：普通历史运行跨股票终止上市时保留持仓资产，按已证退出事实估值并解释；缺证状态可追溯、可恢复。承接 #752（roster 冻结 `delist_date`、`delisted` 参与状态）与 #756（停牌/ST/未知状态）。ETF 终止上市按 #764 另行处理。

## 退出事实与估值语义

- **退出事实**：请求时冻结的 roster `delist_date`（源头为 Tushare `stock_basic` 的 `list_status=D` 身份，经 instrument master 摄录；随 `historical_inputs` 工件持久化）。#756 已留档：日频 `stock_status` 一律 `list_status="L"`，不构成退市证据。
- **退出前**：报价、成交、涨跌停与费用沿用既有逐日规则（含退市整理期真实成交）。
- **退出日起**：参与状态 `delisted`、不参加选股、无行情要求；持仓保留（数量不变），估值锚定该证券最后一条已证实测行情（显示报价日期与收盘价），NAV 继续按锚定价计入。不删除证券、不置零、不按最后价虚构清算或回款、无现金移动。卖出意图成为 pending 订单但无行情不成交——成员离池、终止上市都不等于卖出或清算。
- **守卫**：留存行情出现 `trade_date ≥ delist_date` 的行（退出事实与行情冲突）→ `delisted instrument quoted after exit` fail-closed，幻影报价不能进入执行或信号通道（`FrozenHistoryProvider.get_bars`，股票通道）。
- **规则层**：`ordinary_equity_rules` 对历史重建股票放行窗口内的冻结退市事实（live 路径维持 `unresolved listing/exit valuation` 拒绝——live 退出会计未定义）。

## 报告读回

- 逐日参与的 `delisted` 行执行规则追加退出说明：`已退出上市 YYYY-MM-DD; 持仓保留, 估值锚定 YYYY-MM-DD 收盘 X.XX 元; 无退市清算会计证据`（无留存报价时省略锚定句；锚点为估值单时显示原报价日期）。
- 报告 `final_account_state` 读回退出持仓：数量、锚定市值、NAV=现金+Σ市值。池描述与 UI 文案同步改写（旧文案"股票退出或无报价停牌拒绝估值"已不准确）。

## 固定样例、真实运行与真人验收

- **固定样例（系统旅程，正式 UI→真实 API→持久化→再读取）**：`tests/system/backtest-delisting.spec.ts`（fixture `delisting_backtest_app`，登记于 `tooling/dev/system_tests.py`）。
  - 案例一（000033 事实，2017-07-03..10）：先因整理期末日状态缺行失败（`unknown stock status 1005603 2017-07-05`）→ fixture 补状态快照 → 沿原配置新建运行 completed；07-03 买入 67500 股、退出前 07-05/06 调仓卖出（真实交易）、07-07 起无任何卖出成交、期末 59411 股按 1.70 元锚定（100,998.70 元）计入 NAV；退出日参与行含退出说明；导出 JSON 与请求读回逐字一致；旧失败请求不变；键盘/焦点/axe 通过。
  - 案例二（600656 事实 + 退出事实缺证，2016-05-09..16，SSE 2016 无收盘竞价故用市价单）：先因 `missing backtest member/date inputs 1005762 2016-05-13` 失败 → fixture 经 `apply_delisting` 记录 2016-05-13（真实日期）→ 从普通入口新请求（新身份）completed；05-09/10 共买 22700 股并跨退市保留（99,880.00 元锚定）、无卖出成交；退出说明锚定 2016-05-12 收盘 4.4 元；旧失败请求不变。
  - 案例二的行情到 05-12 为合成（生产库真实缺 05-12 行，正是 #799 缺口）；06 月预热价格与 600656 4.40 元价格为合成数据。
- **单测**：退出后行情冲突守卫（execution/非 execution 双通道）、`exit_held_valuation_notes`（锚定/无锚定/非股票/估值单锚点日期）、`ordinary_equity_rules` 历史放行与 live 拒绝、`Account.mark_to_market` 无报价保留锚定（不删/不零/不动现金）、brokerage 无行情卖出不成交不清算、`freeze_roster` 冻结退出事实与重试复用语义。
