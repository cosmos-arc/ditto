# 仓库知识归属与生命周期

**状态**：Accepted
**日期**：2026-09-08

GitHub Issues 是复杂任务的规格、验收条件、进度和跨会话交接的权威位置；仓库维护长期知识，根 docs 统一导航与跨项目规范，局部说明靠近所属模块，每项现行规则只保留一个事实源。长期设计与 ADR 留在仓库，普通已替代历史材料经引用核查后从当前目录树移除，以 Git 历史追溯。

文档路径中的可执行契约、生成器输入和测试基线按实际用途管理，迁移必须同步使用方，不能按目录名或年代认定无用。必要基线、不可替代设计源和精简证据索引留在仓库；完整发布证明随 Release 长期保存，普通运行输出按 CI 策略留存。任何唯一材料在可靠保存位置落实前继续保留。

这比保留所有历史快照减少了现行事实入口的歧义，但增加了引用追踪和证据归属的维护责任；历史任务通过 Issue 与 Git 基线访问。具体移动、删除和本地缓存处置仍须以清单和依赖核查为依据。

决策来源：[Issue 111](https://github.com/cosmos-arc/ditto/issues/111) 的已确认决定。
执行规则见[任务交付](../engineering/development-workflow.md)与[知识生命周期](../engineering/knowledge-lifecycle.md)。
