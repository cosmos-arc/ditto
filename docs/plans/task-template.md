# Issue 内容提纲

本提纲用于 GitHub Issue 正文；不复制成仓库中的第二份任务状态。

- **目标与边界**：具体问题、预期行为、已确认约束和不做事项。
- **实现决定**：依据的当前源码/契约、职责归属和已确认取舍。
- **验收**：公开行为、必要反例、Task 命令和成功条件。
- **交接评论**：固定基线与当前提交、实际验证结果、已完成内容、剩余事项及下一步。
  实施类任务另附效果度量对照字段：验收一次通过与否、返工提交数、人工干预次数、
  重复验证次数、token 用量与实际耗时；自报体感不作为证据，
  口径见[Harness 效果度量基线](../research/2026-09-12-harness-effect-baseline.md)。

复杂任务按依赖拆分交付，普通可逆小任务直接实现；遵循[任务交付指南](../engineering/development-workflow.md)。
