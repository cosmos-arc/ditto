# 一期上线目标差距分析 — T0 标杆视角

**日期**: 2026-03-24
**审计基准**: T0 机构级量化研究基础设施（Two Sigma / Renaissance / Citadel 级别）
**目标市场**: A 股 ETF + 股票，日频交易策略
**策略类型**: 轮动、趋势追踪、选股，兼顾 Regime 感知与宏观分析

## 1. T0 标杆定义

T0 不是 QuantConnect（T1 = 9-10 分的平台产品），而是机构级量化研究与交易基础设施——在每一个维度上都达到或超越业界最佳实践。

| 维度 | T1 (QuantConnect) | T0 (机构级) |
|------|-------------------|-------------|
| 因子引擎 | 手动定义 200 指标 | 自动因子挖掘 + 因子组合优化 + 因子衰减监控 |
| 回测保真度 | 日频 bar 模拟 | 分钟级/Tick 级模拟 + 真实市场冲击模型 + 滑点建模 |
| 统计分析 | Sharpe/Sortino/DD | 因子归因 + Brinson 归因 + VaR/CVaR + 尾部风险 + 条件分布 |
| 风控 | Per-step RiskGuard | 多层级风控（单标的/组合/策略/账户）+ 压力测试 + 实时监控 |
| 研究工作流 | 云端 IDE + 项目管理 | 可复现研究 + 实验对比 + 一键回测→生产 + 完整审计链 |
| Regime | 无内置 | 多模型集成 + Regime-conditional 因子有效性 + 动态配置 |
| 执行 | 基础市价单 | VWAP/TWAP 算法 + 智能拆单 + TCA 交易成本分析 |
| 数据 | 标准化 API | 多源融合 + 数据质量自动修复 + PIT 修正审计 |

### 4.3 L3 Regime + 宏观分析 — 新建

#### 4.3.1 宏观因子构建引擎

**当前状态**：tushare/FRED 能采集 M0/M1/M2、LPR、MLF、GDP、CPI/PPI、汇率、社融等原始数据，但只存不加工。

**一期需要建设的宏观因子体系**：

| 宏观维度 | 代表因子 | 数据来源 | 计算逻辑 |
|---------|---------|---------|---------|
| **增长** | GDP 同比、PMI、工业增加值 | tushare | 同比/环比/MoM 动量 |
| **通胀** | CPI 同比、PPI 同比、CPI-PPI 剪刀差 | tushare | 同比 + 差值 + 趋势 |
| **流动性** | M2 同比、社融同比、Shibor | tushare | 同比 + MoM 变化 |
| **信用** | 信用利差（AA-AAA）、M2-M1 剪刀差 | tushare | 差值 + 趋势 |
| **情绪** | 换手率、融资余额/流通市值、新增开户数 | tushare | 标准化 + Z-score |
| **汇率** | USD/CNY、人民币中间价 | tushare | 动量 + 偏离度 |
| **外部** | 美元指数、10Y 美债、VIX | FRED | 动量 + Z-score |

**建设要点**：
- 复用现有 ExpressionCompiler 做宏观因子计算，或新建 `MacroFactorEngine`（宏观因子通常是月频/季频）
- PIT 版本控制（宏观数据常修正，需记录发布时间 vs 实际发生时间）
- 与现有 `DerivedSpec` / materialization 体系集成

**估算**：~1.5w

#### 4.3.2 Regime 识别引擎

**一期方案：规则型 + 统计型混合**

```
RegimeEngine
├── MarketRegimeDetector（市场 regime）
│   ├── TrendRegime: MA20/MA60 多空排列 + 价格相对位置
│   ├── VolatilityRegime: 历史波动率分位数（低/中/高/极高）
│   └── CompositeRegime: 趋势 × 波动率 → 4 象限
│         ┌──────────┬──────────┐
│         │ 低波震荡  │ 低波趋势  │
│         │(防御轮动) │(趋势跟踪) │
│    ┌────┼──────────┼──────────┤
│         │ 高波震荡  │ 高波趋势  │
│         │(空仓/对冲)│(强势趋势) │
│    └────┴──────────┴──────────┘
│
├── MacroRegimeDetector（宏观 regime）
│   ├── GrowthCycle: PMI 趋势 + 工业增加值方向
│   ├── LiquidityCycle: M2 同比趋势 + Shibor 方向
│   └── CompositeMacro: 增长 × 流动性 → 4 象限
│         ┌──────────┬──────────┐
│         │ 滞胀      │ 复苏     │
│         │(减仓)     │(加仓)    │
│    ┌────┼──────────┼──────────┤
│         │ 衰退      │ 过热     │
│         │(空仓)     │(中性)    │
│    └────┴──────────┴──────────┘
│
└── IntegratedRegime: Market × Macro → 最终 regime 信号
```

**建设要点**：
- `RegimeDetector` Protocol：`detect(market_data, macro_factors, date) -> RegimeSignal`
- `RegimeSignal` frozen dataclass：regime_type, confidence, features, as_of_date
- 与现有 `RegimeStage`（已在 strategy pipeline 中定义）对接
- 回测中需要验证 regime 标注的历史准确性

**估算**：~2w

#### 4.3.3 Regime-conditional 因子有效性分析（T0 新增）

同一因子在不同 regime 下 IC 差异巨大。T0 要求因子权重能根据 regime 动态调整。

| 能力 | 说明 |
|------|------|
| Regime 分组 IC 计算 | 按 regime 分组计算各因子 IC/RankIC |
| 因子-Regime 交叉分析 | 识别哪些因子在哪些 regime 下有效 |
| 动态因子权重 | 根据 regime 调整因子组合中的权重 |

**估算**：~2d

#### 4.3.4 Regime-aware 策略适配层

| 适配维度 | 机制 | 示例 |
|---------|------|------|
| **仓位控制** | Regime → max_exposure | 高波震荡: max 30%, 低波趋势: max 90% |
| **策略切换** | Regime → active_strategy | 趋势 regime → trend_following, 震荡 regime → rotation |
| **参数调整** | Regime → param_override | 高波 → 缩短均线周期, 低波 → 放宽止损 |
| **风控阈值** | Regime → risk_params | 高波 → max_drawdown 5%, 低波 → max_drawdown 15% |
| **行业偏好** | Macro regime → sector_weight | 复苏 → 周期/可选, 衰退 → 必需/防御 |

**建设要点**：
- `RegimeConfig` 作为 StrategySpec 的可选配置段
- `RegimeAwareConstraint` 作为 DecisionStage 插入 pipeline
- 与现有 `ConstraintChecker`（MaxWeight/MinWeight/MaxPositions）协同

**估算**：~1w

**L3 合计**：~5w

### 4.4 统计增强 — 新建（T0 新增）

当前 `AlphaStatistics` 只有 Sharpe/Sortino/DD 等基础指标，远不满足 T0 要求。

| 缺失统计能力 | 为什么 T0 必须 | 估算 | 优先级 |
|-------------|---------------|------|--------|
| **因子归因分析** | 不归因就不知道收益来源，无法判断 alpha 是否真实 | ~3d | P0 |
| **Brinson 归因** | 行业配置 vs 选股贡献分解，轮动策略的命脉 | ~2d | P0 |
| **VaR / CVaR** | 尾部风险度量，风控和资金管理的基石 | ~2d | P0 |
| **滚动统计窗口** | 策略稳定性判断，防止过拟合 | ~1d | P1 |
| **月度/季度分拆** | 识别策略在特定时段的失效模式 | ~1d | P1 |

#### 因子归因分析详细设计

```
FactorAttribution
├── 收益归因分解
│   ├── 因子暴露（每个因子的 beta）
│   ├── 因子贡献（每个因子对收益的贡献 = beta × factor_return）
│   ├── 残差收益（alpha = 总收益 - 因子收益）
│   └── 解释度（R² = 因子收益 / 总收益）
│
├── 风险归因
│   ├── 因子风险贡献
│   ├── 残差风险
│   └── 跟踪误差分解
│
└── 时序归因
    ├── 滚动因子暴露变化
    ├── 因子贡献时序图
    └── 换手归因（交易成本 vs 因子切换）
```

#### Brinson 归因详细设计

```
BrinsonAttribution
├── 配置效应（Allocation Effect）
│   └── 行业权重偏离基准产生的收益
├── 选股效应（Selection Effect）
│   └── 行业内选股优于/劣于行业平均产生的收益
├── 交互效应（Interaction Effect）
│   └── 行业配置 × 行业内选股的交叉贡献
└── 总超额收益 = 配置 + 选股 + 交互
```

**统计增强合计**：~9d（~1.5w）

```
ParameterStability
├── 参数扰动测试
│   ├── 对每个参数 ±10%/±20%/±50% 扰动
│   ├── 记录 Sharpe/Return/DD 变化幅度
│   └── 敏感度排序 → 识别脆弱参数
│
├── 参数热力图
│   ├── 双参数交叉网格搜索
│   └── 可视化参数空间中的稳定区域
│
└── 过拟合指标
    ├── 参数数量 vs 样本量比
    └── 样本外衰减比率
```

#### Walk-Forward 验证

```
WalkForwardValidator
├── 滚动窗口
│   ├── 训练窗口: [t-N_train, t]
│   ├── 验证窗口: [t+1, t+N_validate]
│   └── 步进: 每次前进 N_validate 天
│
├── 扩展窗口（可选）
│   ├── 训练窗口: [t_start, t]（不断扩大）
│   └── 验证窗口: [t+1, t+N_validate]
│
└── 输出
    ├── 每段训练/验证的 Sharpe/Return/DD
    ├── 样本外 Sharpe vs 样本内 Sharpe 衰减比
    └── 策略是否在样本外保持正 alpha
```

**策略验证合计**：~7d（~1w）

### 4.6 风控增强 — 新建（T0 新增）

当前 PreTrade（6 规则）+ PostTrade（4 规则）是基础版，T0 要求多层级、多维度风控。

| 缺失风控能力 | 说明 | 估算 | 优先级 |
|-------------|------|------|--------|
| **Beta 对冲监控** | 组合 Beta 偏离目标的预警/自动调整 | ~2d | P1 |
| **行业集中度动态控制** | 行业暴露上限 + 偏离预警 | ~2d | P1 |
| **尾部风险监控** | VaR/CVaR 实时计算 + 超限自动减仓 | ~2d | P1 |

#### 多层级风控架构

```
RiskControl (T0 架构)
├── 单标的级（现有 PreTrade 扩展）
│   ├── NoShortSell / PriceValidity / LotSize / BuyingPower
│   ├── ConcentrationPreCheck / DailyTurnoverPreCheck
│   └── 【新增】流动性检查（日均成交额 / 持仓市值）
│
├── 组合级（现有 PostTrade 扩展）
│   ├── MaxDrawdown / SingleLossLimit / ConcentrationLimit / MarketAnomaly
│   ├── 【新增】Beta 偏离监控（组合 Beta vs 目标 Beta）
│   ├── 【新增】行业集中度监控（单行业暴露上限）
│   └── 【新增】VaR/CVaR 尾部风险监控
│
├── 策略级（新增）
│   ├── 单策略最大回撤限制
│   ├── 策略间相关性监控
│   └── 策略资金预算控制
│
└── 账户级（新增，后期实盘需要）
    ├── 总杠杆限制
    ├── 总持仓集中度
    └── 日内亏损熔断
```

**风控增强合计**：~6d（~1w）

### 4.7 研究工作流 — 增强（T0 新增）

| 缺失工作流能力 | 说明 | 估算 | 优先级 |
|---------------|------|------|--------|
| **实验对比框架** | 多次回测结果的标准化对比 + 统计显著性检验 | ~3d | P1 |
| **可复现性保证** | 代码 + 数据版本 + 参数 + 随机种子 → 完整复现 | ~2d | P1 |

#### 实验对比框架

```
ExperimentComparison
├── 多 Run 标准化对比
│   ├── 指标矩阵（Sharpe/Return/DD/IR/Turnover/...）
│   ├── 改进/退化分类（MetricsDelta，已有基础）
│   └── 指标热力图对比
│
├── 统计显著性检验
│   ├── 收益序列差异的 t-test / Mann-Whitney U test
│   ├── Sharpe 差异的 Jobson-Korkie test
│   └── 超额收益的 bootstrap 置信区间
│
└── 策略排行榜
    ├── 按多维度排序
    └── Pareto 前沿（收益-风险-换手率三维）
```

#### 可复现性保证

```
Reproducibility
├── RunManifest（已有基础，需补全）
│   ├── config_hash（已有）
│   ├── rule_refs（已有）
│   ├── data_version_ref（需新增）
│   └── code_version_ref（需新增）
│
├── 数据快照引用
│   └── 每次 Run 记录使用的数据文件 checksum
│
└── 环境记录
    └── 引擎版本 + 依赖版本 + 随机种子
```

**研究工作流合计**：~5d（~1w）
