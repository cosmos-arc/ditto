# Ditto 前端产品设计方案 — 一期研究全链路

## Context

Ditto 后端 API 已具备数据查询、回测执行、因子分析等能力，但 `apps/web` 完全空白。一期目标是从机构级量化平台（T0 标杆）视角，构建覆盖研究全链路的前端产品，包括 Dashboard、数据浏览、策略管理、回测执行/结果/对比、因子分析、Regime 可视化、实验对比、报告导出。

**技术选型**：Next.js 15 + TypeScript + shadcn/ui + Tailwind CSS 4 + Zustand + ECharts + TradingView Lightweight Charts
**一期范围**：研究全链路（覆盖后端全部已实现 + 一期计划中的能力）
**不需要**：策略代码编辑器（一期策略通过配置/JSON 定义）

---

## 1. 业界对标调研结论

### 1.1 参考平台与对标维度

| Ditto 功能模块 | 最佳参考平台 | 核心参考点 |
|---------------|------------|-----------|
| 回测结果 UI | **QuantConnect LEAN** | 9 内置图表 + 20+ 统计指标 + 多 Tab（Overview/Orders/Trades/Logs） |
| 因子研究 | **RiceQuant RQFactor + JoinQuant jqfactor** | 单/多因子分析报告、IC/IR 衰减曲线、分层回测 |
| 组合管理 | **Bloomberg PORT + TWS Risk Navigator** | 钻取层级（组合→行业→标的）、What-If 分析 |
| 风控监控 | **TWS Risk Dashboard + Bloomberg PORT** | VaR 实时监控、暴露限制仪表盘 |
| 数据中心 | **RiceQuant RQData + WorldQuant Data Browser** | 多维度筛选、预览、下载 |
| 策略管理 | **QuantConnect Project Management** | 版本管理、状态标签、克隆/归档 |
| 报告生成 | **QuantConnect Report + pyfolio Tear Sheet** | 可定制 HTML/PDF、月度收益热力图 |
| 图表交互 | **TradingView + QuantConnect** | 十字线、缩放同步、多面板联动 |

### 1.2 关键设计原则（从业界提炼）

- **暗色主题默认**：所有量化平台标配，A 股红涨绿跌
- **模块化面板布局**：可拖拽/调整大小的 Dashboard
- **2 秒评估原则**：P&L 和持仓状态始终可见，一眼判断好坏
- **钻取层级**：组合 → 行业 → 标的 → 交易 → 指标
- **跨图表时间同步**：缩放一个图表，所有图表联动
- **可导出报告**：HTML/PDF 一键生成

## 4. 前端技术架构

### 4.1 技术栈

| 层级 | 选型 | 理由 |
|------|------|------|
| 框架 | **Next.js 15** (App Router) | SSR/SSG、API Routes、React 生态最丰富 |
| 语言 | **TypeScript 5** | 类型安全，量化平台数据模型复杂 |
| UI 库 | **shadcn/ui** | 暗色主题内置、copy-paste 模式、高度可定制 |
| 样式 | **Tailwind CSS 4** | 与 shadcn/ui 原生集成、原子化 CSS |
| 状态管理 | **Zustand** | 轻量、TypeScript 友好、React 生态主流 |
| 金融图表 | **TradingView Lightweight Charts v5** | K 线图专用，35kB，70+ 指标 |
| 分析图表 | **Apache ECharts 6** | 热力图/矩阵图/雷达图，支持暗色主题 |
| 通用图表 | **Recharts** (via shadcn/ui) | 净值曲线、回撤图、分布直方图 |
| 数据表格 | **TanStack Table v8 + TanStack Virtual** | 100K+ 行虚拟滚动、排序/筛选/分页 |
| HTTP 客户端 | **ky** (或 **orpc**) | 轻量 HTTP 客户端，TypeScript 类型推导 |
| 代码编辑器 | — (一期不需要) | — |
| 图标 | **Lucide React** | shadcn/ui 内置 |
| 日期 | **date-fns** | 轻量日期处理 |
| 包管理 | **pnpm** | 快速、严格 |

## 5. 需要新增的后端 API

当前后端 API 仅覆盖数据查询，前端需要以下新端点：

### 5.1 回测执行 API

| Method | Path | 说明 |
|--------|------|------|
| `POST` | `/api/v1/backtest/run` | 提交回测任务，返回 run_id |
| `GET` | `/api/v1/backtest/run/{run_id}/status` | 查询回测进度（轮询） |
| `GET` | `/api/v1/backtest/run/{run_id}/result` | 获取回测结果 |
| `GET` | `/api/v1/backtest/runs` | 列出所有回测 Run |
| `DELETE` | `/api/v1/backtest/run/{run_id}` | 取消/删除回测 |

### 5.2 策略管理 API

| Method | Path | 说明 |
|--------|------|------|
| `GET` | `/api/v1/strategies` | 列出所有策略 |
| `GET` | `/api/v1/strategies/{id}` | 获取策略详情 |
| `POST` | `/api/v1/strategies` | 创建策略 |
| `PUT` | `/api/v1/strategies/{id}` | 更新策略配置 |
| `GET` | `/api/v1/strategies/{id}/versions` | 策略版本历史 |
| `GET` | `/api/v1/strategies/{id}/runs` | 策略关联的回测 Run |

### 5.3 因子分析 API

| Method | Path | 说明 |
|--------|------|------|
| `GET` | `/api/v1/factors` | 列出所有因子 |
| `GET` | `/api/v1/factors/{id}/analysis` | 因子分析结果（IC/IR/衰减） |
| `GET` | `/api/v1/factors/{id}/correlation` | 因子相关性矩阵 |
| `POST` | `/api/v1/factors/backtest` | 因子分层回测 |

### 5.4 Regime API

| Method | Path | 说明 |
|--------|------|------|
| `GET` | `/api/v1/regime/market` | 市场 Regime 时间序列 |
| `GET` | `/api/v1/regime/macro` | 宏观 Regime 时间序列 |
| `GET` | `/api/v1/regime/current` | 当前 Regime 状态 |

### 5.5 实验管理 API

| Method | Path | 说明 |
|--------|------|------|
| `POST` | `/api/v1/experiments` | 创建实验 |
| `GET` | `/api/v1/experiments` | 列出实验 |
| `GET` | `/api/v1/experiments/{id}` | 实验详情 |
| `POST` | `/api/v1/experiments/{id}/compare` | 对比分析 + 显著性检验 |

### 5.6 风控 API

| Method | Path | 说明 |
|--------|------|------|
| `GET` | `/api/v1/risk/dashboard` | 风控仪表盘数据 |
| `GET` | `/api/v1/risk/events` | 风控事件列表 |
| `POST` | `/api/v1/risk/stress-test` | 压力测试 |

### 5.7 报告 API

| Method | Path | 说明 |
|--------|------|------|
| `GET` | `/api/v1/report/{run_id}` | 获取回测报告数据 |
| `GET` | `/api/v1/report/{run_id}/pdf` | 导出 PDF |
| `GET` | `/api/v1/report/{run_id}/html` | 导出 HTML |

## 6. 验证方案

### 6.1 前端验收标准

| 验收项 | 标准 |
|--------|------|
| **暗色主题** | 全站暗色主题，A 股红涨绿跌配色 |
| **响应式布局** | 1280px+ 正常显示，支持双屏 |
| **图表交互** | K 线图十字线/缩放、时间范围同步 |
| **虚拟滚动** | 10K+ 行表格流畅滚动 |
| **数据刷新** | Dashboard 数据自动刷新（30s 间隔） |
| **页面加载** | 首屏 < 2s，路由切换 < 500ms |

### 6.2 E2E 测试场景

1. 打开 Dashboard → 查看市场概览 → 点击最近回测 → 查看结果详情
2. 新建回测 → 选策略 → 配参数 → 提交 → 等待完成 → 查看结果
3. 因子库 → 选因子 → 查看分析 → 查看分层回测
4. 回测列表 → 选 2 个 Run → 对比 → 查看显著性检验
