# 计划与设计来源

新任务的规格、进度、验收和跨会话交接记录在 [GitHub Issues](https://github.com/cosmos-arc/ditto/issues)，
执行约定见[任务交付指南](../engineering/development-workflow.md)。本目录保留尚有引用或未确认
可替代的设计来源，不作为另一套持续更新的任务台账；阅读时核对对应 Issue 和当前源码。

长期决定进入 ADR，owner 设计靠近模块；不把完成的计划继续搬进新的 archive。
普通历史经消费者核查后退出当前树，使用[退役清单](../engineering/material-migrations/README.md)
中的提交与路径恢复。仍在 archive 的设计、被引用计划和未知材料保留原语境。

需要组织任务正文时可参考 [Issue 内容提纲](task-template.md)，将内容写入 Issue，而非另建本地进度文件。
