## 1. 概述

### 1.1 设计目标

黄金数据集（Golden Dataset）是用于数据质量对账的精选标的子集，实现以下目标：

| 目标 | 说明 |
|------|------|
| **效率提升** | 减少对账时间，从全量标的缩小到 20-30 个核心标的 |
| **聚焦核心** | 专注高价值标的，提高问题发现效率 |
| **全面覆盖** | 覆盖 A 股市场各类场景，验证边界条件 |

### 1.2 使用场景

- **每日对账**：Tushare 主数据源 vs 通达信辅助数据源
- **数据质量验证**：验证数据摄入的准确性
- **边界条件测试**：验证特殊场景的数据处理

### 1.3 配置方式

- **配置来源**：YAML 配置文件
- **配置粒度**：全局配置（一个黄金数据集适用于所有对账）
- **配置位置**：`config/default/golden_dataset.yml`

## 2. 选择标准

### 2.1 覆盖维度

基于 A 股市场特点和业界最佳实践，黄金数据集应覆盖以下维度：

| 维度 | 说明 | 覆盖要求 |
|------|------|----------|
| **流动性分层** | 高/中/低流动性标的 | 沪深300、中证500、小盘股 |
| **市场板块** | 不同交易板块特点 | 主板、创业板、科创板、北交所 |
| **资产类型** | 不同资产类别 | 股票、ETF（宽基/行业/跨境）、指数 |
| **特殊场景** | 边界条件验证 | ST股、停牌、涨跌停、分红除权 |

### 2.2 选择原则

1. **代表性**：选择各维度最具代表性的标的
2. **稳定性**：优先选择长期存续、数据完整的标的
3. **可验证性**：标的应有多个数据源可对比
4. **敏感性**：包含对数据质量敏感的场景

## 5. 架构设计

### 5.1 分层架构

```
┌─────────────────────────────────────────────────────────────────┐
│ Port 层                                            │
│ ┌─────────────────────────────────────────────────────────────┐ │
│ │ GoldenDatasetProvider                                       │ │
│ │ - 加载 YAML 配置                                            │ │
│ │ - 注入 GoldenDatasetSpec 到 DI 容器                         │ │
│ └─────────────────────────────────────────────────────────────┘ │
│ ┌─────────────────────────────────────────────────────────────┐ │
│ │ QualityReconciliationService                                │ │
│ │ - 接收 GoldenDatasetSpec                                    │ │
│ │ - 应用 _apply_golden_dataset_filter()                       │ │
│ └─────────────────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────────┘
                              ↓ DI
┌─────────────────────────────────────────────────────────────────┐
│ Core 层                                          │
│ ┌─────────────────────────────────────────────────────────────┐ │
│ │ golden.py                                                   │ │
│ │ - GoldenDatasetSpec: Pydantic 模型                          │ │
│ │ - GoldenDatasetOptions: 选项配置                            │ │
│ └─────────────────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────────┘
```

### 5.2 数据模型

```python
# packages/core/src/ditto_core/quality/golden.py

class GoldenDatasetOptions(BaseModel):
    """黄金数据集选项。"""
    enabled: bool = True
    dynamic: DynamicConfig | None = None

class GoldenDatasetSpec(BaseModel):
    """黄金数据集配置规范。"""
    description: str = ""
    tickers: list[str] = []
    options: GoldenDatasetOptions = GoldenDatasetOptions()

    @property
    def is_enabled(self) -> bool:
        """是否启用。"""
        return self.options.enabled and len(self.tickers) > 0

    def get_tickers(self) -> list[str]:
        """获取有效 ticker 列表。"""
        return self.tickers if self.is_enabled else []
```

## 6. 对账服务集成

### 6.1 过滤流程

```
daily_reconciliation(primary_df, trade_date)
    │
    ├─ 1. 验证输入（包含 instrument_id）
    │
    ├─ 2. enrich_with_ticker() → 添加 ticker 列
    │
    ├─ 3. _apply_golden_dataset_filter() → 【新增】过滤到黄金标的
    │       │
    │       ├─ 检查 is_enabled
    │       ├─ 获取 golden_tickers
    │       └─ filter(ticker.is_in(golden_tickers))
    │
    ├─ 4. 获取 TDX 辅助数据
    │
    ├─ 5. 调用 QualityEngine.check_cross_source()
    │
    └─ 6. 存储结果 + 触发告警
```

### 6.2 过滤实现

```python
def _apply_golden_dataset_filter(self, df: pl.DataFrame) -> pl.DataFrame:
    """应用黄金数据集过滤。"""
    if not self._golden_dataset or not self._golden_dataset.is_enabled:
        return df

    golden_tickers = self._golden_dataset.get_tickers()
    return df.filter(pl.col("ticker").is_in(golden_tickers))
```

## 7. 扩展能力

### 7.1 用户自定义配置

用户可在 `{data_root}/config/golden_dataset.yml` 创建自定义配置，覆盖默认配置。

### 7.2 动态标的（未来扩展）

- **次新股**：自动纳入上市 N 天内的新股
- **停牌股**：可配置是否纳入停牌股
- **ST股**：可配置是否纳入 ST 股
