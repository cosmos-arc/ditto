## 2026-09-20 核心旅程与顺序修订

维护者已确认[核心旅程与建设顺序](https://github.com/cosmos-arc/ditto/issues/242)的三项决定：

- 股票与 ETF 均属首期完整旅程，可分批交付。股票覆盖选池、研究、组合、Paper 与复盘；ETF 覆盖暴露选择、工具比较、配置与复盘，不以行情页代替。
- 正常旅程无需手填内部 ID/hash/JSON 或 CLI 救援；高级导入保留。真实状态、跨页上下文和失败恢复必须可用，页面存在与视觉 parity 不能代替用户任务验收。
- 数据与恢复优先；核心交互、图表语义和数据取证可以并行。ML 的数据与研究协议就绪即可启动，不等待全部布局记忆、右键、Toast 或 MCP。前向使用独立记录，不追溯改变旧发布 Gate。

本修订替代下文“先还全部 parity 债，再谈新交互”与第四节的全局串行顺序；交互效率票按上述核心旅程先交付，其余既有范围保留为后续批。图表已合入切片不重新实施。数据准入与估值收益已在各自决策票确认；ML/文本协议见下文当前修订。Agent 边界与技术栈见下文 D17 修订；架构与治理决定见末节。

## 二、各票裁决摘要

### #195 交互效率（设计定稿）

⌘K 真接线（导航=页面+对象搜索，动作=创建/发起/偏好，频率排序）；通用 EntityPicker 替换全部手填内部 ID/粘贴 JSON；`react-resizable-panels` 落地 Workspace Memory（约束按 20 号审计表：Rail 固定 48–56px、右栏 170px–40% viewport 可折叠、主区 ≥40%），localStorage 页面级持久化；右键最小集（图表/表格行/对象页 header）；Toast=L1 反馈统一；StatusBar 接真实 healthz/readyz 并删除硬编码假值。

### #197 条件式 Screener（设计定稿）

**run-first 防退化**为首要约束（实施计划 §24 已注册「选股工作台退化为筛选器」风险）：条件构建器的产物是可保存、可比较、可重放的 SelectionSpec/Run（带 reason code 与排除证据链），不是临时结果页。条件字段分组映射既有 102 FactorSpec 的 12 类；PIT 合格列才可入条件；结果表为 Analytical 子类型；不做自然语言输入（留给 D17 会话层）。

### D17 研究 Agent 交互（2026-09-20 当前裁决）

依据：[研究 Agent 产品边界](https://github.com/cosmos-arc/ditto/issues/247)与[ADR 0014](../adr/0014-agent-sdk-agui-goalx-alignment.md)。维护者确认自然语言连续研究、上下文与权限边界、真实 Campaign 和按需 MCP，并指定与 GoalX 使用一致的 AG-UI / OpenAI Agents SDK 技术栈及交互。

1. 原始要求、修订和可查看/确认的结构化摘要可跨轮保留；业务对象内自然语言追问、流式回答、来源/时点、证据弱点及错误反馈对齐 GoalX。撤销旧版“不携带自由文本”和“禁止社交气泡”的强限制，仍不设脱离研究对象的全局聊天入口。
2. 复用既有 session/run，每轮独立审计；跨 session 延续同一研究的预算/试验族，权限与证据有效性重新核验，历史审批不自动授权新动作。
3. 沿用 Python OpenAI Agents SDK；FastAPI + ag-ui-protocol 对外，React useChat + @ag-ui/client 薄 transport 对内。无 Node BFF、无第二 Agent/UI 框架；复用 Ditto token、业务组件与模型供应商配置。
4. AG-UI 投影真实运行与持久化事件，保留顺序、终态、取消和重连重放；不因刷新/重试重复执行工具。工具经 application，审批、PIT、预算和审计由服务端掌握。
5. 先复核已有 OCI 范围再跑单轴 Campaign，安全与研究效果分验；MCP 先用 Codex 验证数据质量、证据读取、组合比较三项只读任务，不阻塞核心工作台。

实施沿用既有票，SDK/协议版本与恢复适配须实际验证，不能以 GoalX 当前单问追问能力替代 Ditto 多轮研究验收。本次只改规格。

### ML 与文本研究协议（2026-09-20 当前裁决）

依据：[确定 ML 与文本研究协议：标签成熟、最终测试与前向验证](https://github.com/cosmos-arc/ditto/issues/244)。替代原模型管线与文本因子段落，与上述当前 D17 并行生效。

- 股票先完成规则、线性模型和 LightGBM 的同口径训练→预测→组合→Paper 闭环；ETF 先建立可解释配置基线。复用既有实验与回测能力，不新建 ML 一级平台。
- 标签必须在训练截止时成熟，按交易日期切分，预处理拟合限于训练范围；按实际标签区间验证隔离。每个滚动模型及特征/数据/代码身份可追溯，重启能恢复，缺特征或版本不匹配时停止出信号。
- 开发验证与最终测试隔离；人或 Agent 据最终结果继续选择后，不再称未见测试。记录完整试验选择，PBO/DSR 按适用条件报告；晋级标准预先确定，前向观察单独留证。模型卡片不替代实际推理，正收益不是实现完成的条件。
- 文本先选一类公告事件，验证抽取准确率、引用和可用时间，再检验增量；区分公开、可得、首次观察与修订时间。历史回测保留预训练污染标记，冻结模型后做前向验证；保存原始响应和打分工件，区分审计重放与重新调用。
- 研报与全市场情感后置。具体事件、模型、数据权益、标签期限及数值阈值在实施设计中基于样本明确，不沿用未经核实的固定加购价格或模型预设；不授权本轮采购、安装依赖或运行真实数据。

实施规格：[时间正确的截面 ML 训练、推理与组合评价](https://github.com/cosmos-arc/ditto/issues/201)、[公告事件抽取与文本因子前向验证](https://github.com/cosmos-arc/ditto/issues/202)。

## 2026-09-20 架构与治理最终决定

维护者已确认 catalog 按操作风险简化、清理前核实消费者与独有保障；不以单人使用为由取消高影响动作的授权、审计或恢复，不以端点或删除数量验收。

application 明确以架构合理性、内聚和分层清晰为目标，无减半配额。依据[架构调研](../research/2026-09-20-application-architecture-principles.md)，维护者已[确认](https://github.com/cosmos-arc/ditto/issues/248)先校准研究数据集读写/导出边界，再校准研究统计定义与规则归属；保留三组合聚合、选股编排、恢复与幂等。本轮规划定稿，不直接实施产品代码或修改机器边界。
