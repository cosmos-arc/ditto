## 3. Phase 0.5：数据质量验证期（~2 周）

### 3.1 目标

这是**专门增加的阶段**，用于确保数据基础的正确性。

> "数据错了，后面一切都是错的。"

### 3.2 任务清单

| 任务 | 预估工时 | 验收标准 |
|------|----------|----------|
| 选取 Golden Dataset 标的 | 2h | 3 只 ETF + 1 只指数 |
| 手工核验收盘价（100 天） | 8h | 与东财/同花顺网页数据对比 |
| 手工核验复权因子 | 8h | 找到有分红日期，验证复权计算 |
| 手工核验涨跌停状态 | 4h | 抽查 10 个涨跌停日期 |
| 数据质量基线报告 | 8h | 输出《数据质量基线报告 v1》 |
| 修复发现的问题 | 16h | 预留时间 |

**总工时**：~46h（约 2 周）

### 3.3 Golden Dataset 选取

| 标的 | 代码 | 选取原因 |
|------|------|----------|
| 沪深300 ETF | 510300.SH | 流动性最好，基准 |
| 游戏 ETF | 516010.SH | 流动性较差，测试极端情况 |
| 纳指 ETF | 513100.SH | 跨境 ETF，有溢价和熔断 |
| 沪深300 指数 | 000300.SH | Regime 基准指数 |

### 3.4 验收检查

```markdown
# 数据质量基线报告 v1 必须包含：

1. 各标的数据完整性（缺失率）
2. 价格准确性（与权威来源对比）
3. 复权因子验证结果
4. 涨跌停识别准确率
5. 已知问题清单
6. 数据源可靠性评估
```

## 4. Phase 1：回测闭环与调仓计划（~6 周）

### 4.1 目标

- 完成 Regime / Factor 引擎
- 实现RotationStrategy、RegimeAwareStrategy、FactorBasedStrategy
- 实现动态因子权重
- 完善PortfolioManager、信号聚合逻辑、风险预算检查、配置驱动
- 完成双回测引擎并通过对齐测试
- 实现实现CostSensitivityAnalyzer
- 实现StressTester
- 实现WalkForwardValidator
- 实现BacktestOrchestrator回测编排及报表
- 完成风控引擎（含回撤速度检测）
- 完成心跳机制
- 能生成可用的调仓计划
- 完成成本模型 + 执行路由 + 执行分析

### 4.4 验收标准（严格版）

```python
# 对齐测试必须满足
assert abs(fast_result.total_return - prod_result.total_return) < 0.001  # 0.1%
assert abs(fast_result.max_drawdown - prod_result.max_drawdown) < 0.005  # 0.5%
assert fast_result.rebalance_count == prod_result.rebalance_count         # 完全一致
assert fast_holdings == prod_holdings                                     # 每日持仓完全一致

# 回测可复现性
assert run1_result == run2_result  # 相隔 1 天运行两次，结果完全一致

# 历史关键时点验证
assert backtest_2015_06.max_drawdown < 0.25  # 2015年6月股灾
assert backtest_2020_03.max_drawdown < 0.15  # 2020年3月新冠
assert backtest_2022_04.max_drawdown < 0.20  # 2022年4月熊市

# 边界条件测试
assert universe_1_etf_backtest.passes           # Universe 只有 1 只 ETF
assert period_1_month_backtest.passes           # 回测期只有 1 个月
```

- 完成纸面交易闭环验证

高级特性

- 动态资金再平衡
- ML学习因子权重

| 任务 | 说明 |

## 7. 风险与缓冲

### 7.1 已识别风险

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| Tushare 限流 | 数据采集延迟 | +1 周 buffer，AkShare 降级 |
| 对齐测试困难 | Phase 1 延期 | +1 周 buffer，已预留 16h 调优时间 |
| 数据质量问题 | 回测结果不可信 | Phase 0.5 专门验证 |
| 复权因子错误 | 收益计算错误 | 手工核验 Golden Dataset |

### 7.2 时间 Buffer

- Phase 0：预留 0.5 周 buffer
- Phase 0.5：预留 0.5 周 buffer
- Phase 1：预留 1 周 buffer

**总 Buffer**：~2 周
