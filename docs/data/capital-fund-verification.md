# 交易资金面核验报告（#625 / 父规格 #621 P3）

实测时间：2026-10-31（数据至 2026-10-30 夜链之后；margin 历史回补同日执行）。
覆盖 #625 四项范围：个股资金流逐证券覆盖核验（非重拉）、融资融券通路修复与
历史回补、ETF 场内份额历史核验与尾部补齐、分页截断可检测。

复测入口：

```bash
DITTO_STATE_ROOT=<data root> DITTO_CONFIG_ROOT=<repo> DITTO_CACHE_ROOT=<cache> \
  python -m ditto_apps.cli.main ops audit-capital-coverage \
    --dataset moneyflow|fund_share --start 2014-01-01 --end <最新交易日> [--json]
```

`DITTO_CONFIG_ROOT` 必须指向**仓库根**（同 #624 实测教训，见
price-identity-verification.md）。

## 能力交付（CODE）

- **分页截断可检测**（`sources/tushare/client.py`）：短页后追加一行续探
  （offset 处 limit=1）——出现**未见过的行**即截断实锤，按观测到的服务端
  上限降页宽续拉（自愈），`tushare_pagination_truncation_detected` 告警留痕；
  上限低于 500 时 fail-closed 拒收。探针行已见于已见集合 = 越界回显首页形态
  （#431），按取尽处理。探测请求瞬态失败按取尽处理（fail-open 于探针，
  不否决已取回数据）。离线复现契约：2501 行源 cap 2000 完整取回（旧）；
  10202 行源 cap 8500 页宽 9000 自愈完整取回（新）。
- **页宽契约补档**（`utils/pagination.py`）：margin_detail=6000（doc_id=59
  「单次请求最大返回 6000 行」）、fund_share=2000（doc_id=207）——此前两者
  落保守默认 2000，margin_detail 全市场日 ~4,486 行单页取尽。
- **晚发布近窗重取**（`backfill_manager.backfill_missing(force_refresh_days)`
  + `repair.py LATE_PUBLISHING_REFRESH_DATASETS`）：margin_detail 官方口径
  「交易所每日约上午 8:30 更新上一交易日；深市/北交所周五数据下周一上午
  更新」（doc_id=59）——21:55 EOD 波恒空；fund_share 源侧批量补发节奏
  （10-26 实测 765/1807 部分行）。SUCCESS/空帧或部分行被 skip 决策固化后
  空洞扫描不可见；nightly repair 对 margin_trading/fund_share force 重取
  近 5 个交易日，同业务键幂等合并（SQLite ON CONFLICT / Parquet 同 kd
  upsert），空观察重取经 evidence `:revision:` 检查点留痕。
- **覆盖审计扩展**（`processes/quality/coverage_audit.py`）：dataset 档位
  moneyflow（stock 名册 × 日历，停牌归因沿用 stock_status）/ fund_share
  （etf 名册 × 日历，缺口落 no_status_dataset 证据边界）；复用 #624 会话
  网格与闭合词汇表。`MarketService.get_fund_share` 读口 + CLI
  `ops audit-capital-coverage`（失败退出码 1）。
- **margin 列名语义修正**：rzmre（融资买入额·元）此前误标
  `margin_buy_volume`，更名 `margin_buy_amount`（官方 doc_id=59 单位口径；
  margin_trading 表 0 行窗口期改名，活库 ALTER RENAME COLUMN，契约/
  Web 生成物/预检证据三处同步再生；#390 批准的破坏窗口内）。
- margin_trading **不提供**会话覆盖审计：两融标的池无本地名册，期望会话
  不可推导——覆盖事实以本报告实际历史矩阵 + 覆盖合同落档，不伪造。
