## 当前使用原则

Ditto 服务维护者本人盘后研究、次日计划与账户复盘，是本地优先的沪深股票与境内 ETF 工作台，不连接券商下单。本版包括 2014 年起至少十年的三类普通研究，完整 Manual 与独立 Paper；可视条件、因子组合及高级受控公式/规则是研究入口。自由 Python、ML、产品 Agent、MCP 新增能力后置。

当前产品范围已定；[IA](https://github.com/cosmos-arc/ditto/issues/730)和[交互/视觉原型](https://github.com/cosmos-arc/ditto/issues/731)仍待维护者签收。五域、Graphite Studio、右栏、底部区和现有 shell 是候选与复用依据，不能因迁移成本或旧蓝图把布局锁死。探索可以提出更优结构；实施按本批获批方案执行，不把候选自动当授权。

暂停产品 Agent 不妨碍使用开发 Agent 完成已授权设计与实现；不因此建设新 Agent 平台、增加固定角色或多轮评分流程。

## 每次任务的最小输入

提供下列信息即可，不要求新建一组设计文档：

| 输入 | 要说明什么 |
| --- | --- |
| 本次用户任务 | 起点、工作对象、预期结果及范围；引用 PRODUCT 和相应任务票 |
| 阶段 | 设计探索或实施；实施附明确签收的方案，待定处不伪装成已定 |
| 视觉与结构依据 | 具体原型页/截图、适用片段、当前 tokens/组件；标明参考或已签收，不整包传入过时蓝图 |
| 数据与业务状态 | 实际 API/数据边界、正常及本任务必要异常；股票/ETF、普通研究/严格资格、Model/Paper/Manual 的区别 |
| 验收场景 | 起始数据/版本、操作、可核结果、必要拒绝/恢复、主用与较窄桌面视口 |

业务名称、代码、日期、版本与可读参数进入默认工作面；精确来源身份由系统解析、保存并允许下钻。不能把 JSON 输入框称作自由 Python 能力，不能用完整图表掩盖缺证。

## 设计探索模板

> 为 Ditto 的「具体任务」探索信息组织与交互方案。读取 PRODUCT 的当前范围和本批任务，引用指定原型片段与现有 tokens/组件。说明用户如何开始、完成并再次找到结果，以及必要的空、缺失、失败和恢复状态。
>
> 五域、Graphite 和主辅布局是候选依据；若更好的任务组织需要重做，可以提出并说明取舍。不要预设必须有右栏、底部区或固定数量页面。比较候选时采用相同数据、视口和任务；克制、可读的高密度、清楚的金融语义、键盘与焦点保持可用。
>
> 输出可供维护者判断的方案与尚待裁定点，不写成设计已签收，不扩充本版未授权的 Agent、Python、团队或券商功能。

探索只比较足以回答当前问题的方案，不要求每页都做多版本或将工具迁移作为前置。

## UI 实施模板

> 按「已签收方案及版本」完成「具体任务」的正式 UI 与必要消费者。先核对实际 API、现有组件与数据合同，复用已有图表、策略、回测和账户能力；当前缺口明确保留或按本批授权补齐，不能靠放宽 PIT/账户/资格守卫填满界面。
>
> 操作必须兑现：保存后可重开，策略入口携带版本，详情加入比较后在比较工作面可找到，返回保持本任务上下文。Paper 与 Manual 保持事实分离；普通回测不自动取得严格历史、信号或 Paper 资格。2014 目标不能用十只样本或静默缩短期间替代。
>
> 固定样例与真实数据进入同一正式页面和状态合同，真实接口失败不能回退为模拟成功。用现有 tokens 和组件；必要结构变化按获批方案处理，不为统一而新增通用平台或改造无关页面。
>
> 在运行页面完成本任务的正常路径和必要拒绝/恢复，核对真实保存、结果口径与导出。记录实际提交/运行身份、观察到的结果和未验证部分，不以截图、marker、提示文案或测试绿灯代替任务成功。

开发中发现影响任务或账本/PIT 的真实缺口，应先核对消费者与边界并反馈具体原因；不要把实现现状反写为已批准的产品缩减。

## 任务与视觉复核模板

> 从用户任务独立操作运行页面，核对入口、上下文、状态、结果和重开/恢复。以本批选定数据、视口、主题与密度对照获批样板，检查主工作面、表图关系、数字/单位、交互焦点与必要异常。
>
> 对每个问题给出复现操作、预期与实际、影响及证据位置；区分产品功能、数据口径、视觉差异和恢复问题。未知写明未验证，不给无法解释的审美高分。普通研究、严格历史资格、Paper 资格与真人日用证据分别报告。

每条任务使用一份简短验收记录即可；状态和视口按影响选取，不建立所有页面的全组合矩阵。关键任务独立复核，局部调整按实际风险验证；不固定三角色、评分次数或重复全量评审。维护者看真实工作面签收视觉，真人日用周期在逐任务验收后另定。
