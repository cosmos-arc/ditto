## 1. 文档目标

本文件定义回测引擎本身的技术规格，是 **"前端展示回测结果"（02 蓝图 §8）的上游**。

02 蓝图定义了"回测结果长什么样"，本文件定义"回测引擎怎么算出来的"。

定位：**追平聚宽/米筐的回测能力水平**（v1），为内部团队的量化策略验证提供可信基础。

### 设计原则

1. **透明优先**：所有假设必须可配置、可审计、可对比
2. **A 股原生**：涨跌停、停牌、T+1、印花税等规则内置而非外挂
3. **渐进增强**：v1 日线收盘价撮合 → v1.5 分钟线/VWAP → v2 多频率/多模型
4. **防过拟合**：内置 walk-forward 验证和过拟合警告机制

## 2. 撮合模型

### 2.1 v1 撮合模型：收盘价（Close Price）

| 参数 | v1 值 | 说明 |
|------|-------|------|
| 撮合基准 | 当日收盘价 | 策略信号在 T 日收盘后生成，T+1 日以收盘价成交 |
| 执行延迟 | T+1 | 所有信号默认次日执行（与 A 股 T+1 制度对齐） |
| 成交假设 | 全量成交 | 假设信号对应的订单可全部以收盘价成交 |

**适用场景**：日线级别策略验证、因子 IC/IR 测试、策略初筛。

**局限性**：不模拟日内价格波动、不考虑流动性和冲击成本。

### 2.2 v1.5 撮合模型扩展

| 模型 | 触发条件 | 说明 |
|------|---------|------|
| VWAP | 分钟线数据可用 | 以当日成交量加权平均价成交，更接近实际执行 |
| TWAP | 分钟线数据可用 | 时间均匀拆单，以各时段均价成交 |
| Open Price | 分钟线数据可用 | 以次日开盘价成交 |

### 2.3 撮合模型配置界面

Strategy Studio 回测参数面板应暴露：

```
撮合模型: [收盘价 ▼]     执行延迟: [T+1]
滑点:    [0.01%]         最小成交量: [0]
```

## 3. A 股规则模拟

### 3.1 涨跌停模拟

| 场景 | 行为 | 说明 |
|------|------|------|
| 买入信号 + 目标已涨停 | **不成交** | 无法以涨停价买入，信号挂起至次日重新评估 |
| 卖出信号 + 目标已跌停 | **不成交** | 无法以跌停价卖出，信号挂起至次日重新评估 |
| 连续涨停/跌停 | **持续挂起** | 每个交易日重新评估，直到可成交或信号过期 |
| 信号过期 | **自动取消** | 默认挂起 5 个交易日后自动取消 |

**涨跌停板规则**：

| 板块 | 涨跌停幅度 | 最小价格单位 |
|------|-----------|-------------|
| 主板 | ±10% | 0.01 元 |
| ST / *ST | ±5% | 0.01 元 |
| 创业板 | ±20% | 0.01 元 |
| 科创板 | ±20% | 0.01 元 |

### 3.2 停牌模拟

| 场景 | 行为 |
|------|------|
| 信号目标处于停牌 | 不成交，信号挂起 |
| 持仓标的停牌 | 不可卖出，停牌日不计入换手率 |
| 复牌日 | 恢复正常撮合 |

### 3.3 T+1 限制

| 场景 | 行为 |
|------|------|
| 当日买入 | T+1 日起可卖出 |
| 信号为"买入"后紧跟"卖出" | 买入 T+1 后才可执行卖出 |

### 3.4 交易单位

| 规则 | 值 |
|------|-----|
| 最小买入单位 | 100 股（1 手） |
| 卖出 | 支持零股卖出 |
| 价格精度 | 0.01 元（主板）/ 0.01 元（创业板/科创板） |

## 4. 数据频率

### 4.1 v1 数据频率

| 数据类型 | 频率 | 来源 | 用途 |
|---------|------|------|------|
| 日线 OHLCV | 日线 | tushare | 收盘价撮合、策略信号生成 |
| 指数日线 | 日线 | tushare | 基准对比、市场状态判断 |
| 复权因子 | 日线 | tushare | 前复权/后复权处理 |
| 涨跌停标记 | 日线 | tushare | 涨跌停模拟 |
| 停牌标记 | 日线 | tushare | 停牌模拟 |
| 财务数据 | 季度 | tushare | 基本面因子计算 |

### 4.2 v1.5 扩展

| 数据类型 | 频率 | 来源 | 用途 |
|---------|------|------|------|
| 分钟线 OHLCV | 1min / 5min | 通达信（历史）/ MiniQMT（实时） | VWAP/TWAP 撮合 |
| 分时成交 | 逐笔 | MiniQMT | 冲击成本模拟 |
| Level-1 快照 | 3s | MiniQMT | 实时信号验证 |

### 4.3 回测时间范围

| 参数 | v1 默认值 | 说明 |
|------|----------|------|
| 最小回测长度 | 1 年 | 少于 1 年的回测结果标注"样本不足" |
| 推荐回测长度 | 3 年 | 包含至少一个完整牛熊周期 |
| 最大回测长度 | 10 年 | tushare 万积分数据覆盖范围 |
| 样本外比例 | 30% | walk-forward 验证的样本外占比 |

## 5. 复权策略

### 5.1 默认复权方式

| 场景 | 复权方式 | 说明 |
|------|---------|------|
| **回测引擎默认** | **前复权（forward adjustment）** | 以最新价格为基准，历史价格向下调整 |
| K 线图展示 | 前复权 | 与回测引擎一致 |
| 收益率计算 | 不复权（使用复权因子） | 收益率 = (今收盘价 × 今复权因子) / (昨收盘价 × 昨复权因子) - 1 |

### 5.2 复权策略规则

1. **分红除权处理**：除权日自动调整复权因子，回测净值不受分红影响
2. **送股/转增处理**：送股转增日调整复权因子和持仓数量
3. **拆股处理**：同送股处理
4. **复权因子来源**：tushare `adj_factor` 字段

### 5.3 用户可切换

回测配置面板提供复权方式选项：

```
复权方式: [前复权 ▼]  （前复权 / 后复权 / 不复权）
```

> 选择"不复权"时，在回测结果中标注警告："不复权模式下，分红送转会导致净值计算偏差，仅用于特殊分析场景"。

## 6. 成本模型

### 6.1 交易成本

| 成本项 | 费率 | 方向 | 说明 |
|--------|------|------|------|
| 印花税 | 0.05% | 卖出单向 | 2023-08-28 起减半征收（原 0.1%） |
| 佣金 | 0.025%（万 2.5） | 双向 | 可配置，含最低 5 元 |
| 过户费 | 0.001% | 双向 | 2022-07-1 起新标准 |
| 滑点 | 0.01%（默认） | 双向 | 可配置，模拟执行偏差 |
| 冲击成本 | 自动估算 | 双向 | 基于成交量占比估算（v1.5） |

### 6.2 印花税历史分段

回测引擎需支持历史费率分段计算：

| 时间段 | 印花税率 |
|--------|---------|
| 2008-09-19 前 | 0.3%（双向） |
| 2008-09-19 ~ 2023-08-27 | 0.1%（单向，卖出） |
| 2023-08-28 起 | 0.05%（单向，卖出） |

### 6.3 成本配置界面

```
印花税: [自动(历史分段) ▼]  佣金: [0.025%]  最低佣金: [5 元]
滑点:   [0.01%]             过户费: [0.001%]
冲击成本: [自动估算 □]
```

## 7. 容量约束

### 7.1 流动性过滤

| 参数 | v1 默认值 | 说明 |
|------|----------|------|
| 最小日均成交额 | 1000 万元 | 低于此值的标的自动排除 |
| 最大持仓占比 | 5% | 单只标的持仓不超过该股日均成交额的 5% |
| 换手率上限 | 30% | 单日换手不超过该股流通股的 30% |

### 7.2 组合约束

| 参数 | 默认值 | 说明 |
|------|-------|------|
| 最大持仓数 | 50 只 | 分散化要求 |
| 单只最大权重 | 10% | 集中度限制 |
| 行业最大权重 | 30% | 行业集中度限制 |

### 7.3 容量警告

当策略在回测期间触发容量约束时：

- 在回测结果中标注"容量受限交易日"
- 在交易明细中标注"部分成交"及实际成交比例
- 在 KPI Strip 中增加"容量覆盖率"指标

## 8. 幸存者偏差处理

### 8.1 v1 策略

| 方法 | 说明 |
|------|------|
| 回测 Universe | 使用"当时存在"的标的，不包含后来上市的标的 |
| 退市处理 | 退市标的按最后交易日收盘价清仓 |
| ST 标的 | 可配置是否排除（默认包含） |

### 8.2 v1.5 增强

- 回测开始时快照所有在市标的，回测期间新上市标的需等待 N 日后才纳入
- 支持退市标的退市前最后交易日的市值计算

## 9. 过拟合检测

### 9.1 Walk-Forward 验证

| 参数 | 默认值 | 说明 |
|------|-------|------|
| 窗口长度 | 252 个交易日 | 约 1 年的训练窗口 |
| 步长 | 63 个交易日 | 约 1 个季度的滚动步长 |
| 样本外比例 | 30% | 每个窗口的样本外占比 |

### 9.2 过拟合警告指标

| 指标 | 阈值 | 警告级别 |
|------|------|---------|
| 训练集 vs 测试集 Sharpe 差距 | > 1.0 | 🔴 过拟合风险高 |
| 训练集 vs 测试集 Sharpe 差距 | 0.5-1.0 | 🟡 过拟合风险中 |
| 参数数量 / 样本量 | > 1/30 | 🟡 参数过多 |
| 最大回撤恢复天数 | > 252 日 | 🟡 回撤恢复过慢 |

### 9.3 过拟合警告 UI

回测结果页面在 KPI Strip 下方显示过拟合风险指示器：

```
过拟合风险: 🟡 中等  (训练 Sharpe 2.1 vs 测试 Sharpe 1.4, 差距 0.7)
```

## 11. 回测结果数据模型

### 11.1 回测输出

| 数据 | 格式 | 用途 |
|------|------|------|
| 日频净值序列 | `[{date, nav, benchmark_nav}]` | NAV 曲线绘制 |
| 日频持仓 | `[{date, holdings: [{code, weight, shares, cost}]}]` | 持仓分析 |
| 交易记录 | `[{date, code, action, qty, price, fee, reason}]` | 交易明细 |
| 月频收益 | `[{month, return, benchmark_return}]` | 月度收益分析 |
| 年频统计 | `[{year, sharpe, mdd, annual_return, turnover}]` | 年度对比 |

### 11.2 指标计算标准

| 指标 | 计算方式 | 年化基准 |
|------|---------|---------|
| 年化收益 | 复利年化 | 252 交易日 |
| Sharpe | (年化收益 - 无风险利率) / 年化波动率 | 无风险利率取 10 年期国债收益率 |
| 最大回撤 | max(peak - trough) / peak | — |
| Sortino | (年化收益 - 无风险利率) / 下行波动率 | — |
| Calmar | 年化收益 / 最大回撤 | — |
| 胜率 | 盈利交易数 / 总交易数 | — |
| 盈亏比 | 平均盈利 / 平均亏损 | — |
| 换手率 | |sum(|Δweight|)| / 2 / N | 双边计算 |
