# Product

## Register

product

## Users

Ditto 面向全栈个人量化交易者与小型内部量化团队。核心用户每天长时间处理市场数据、策略研究、交易执行、风险监控和系统维护，需要在一个工作台中完成判断、验证和行动。

主要工作角色包括：

- 策略研究员：盘后高频使用 Research、Factor Analysis、Strategy Studio、Backtest Result，关注因子诊断、策略构建、回测可信度和迭代效率。
- 交易执行者：交易时段使用 Home、Trading Overview、Signals Inbox、Orders Ledger、Risk Center，关注信号复核速度、交易约束、风控异常和执行反馈。
- 系统维护者：盘前、盘后使用 Platform、Settings、Agent Console，关注数据源、交易通道、流水线、Agent 运行状态和异常追溯。

用户默认具有金融判断能力和技术理解力，偏好高密度、低噪声、可扫视、可连续使用的专业界面。新手友好不是首要目标，降低误判、减少工具切换、保持长期可信才是核心。

## Product Purpose

Ditto 是个人量化研究与实盘闭环的专业工作台。它把市场观察、标的发现、因子研究、策略构建、回测验证、信号复核、订单执行、风险监控和持续改进连接在同一个系统里。

核心链路是：

Observe → Discover → Research → Validate → Execute → Monitor / Improve

产品成功的标志不是功能数量多，而是用户能够：

- 进入任意页面后 5 秒内理解当前状态、关键风险和下一步动作。
- 在研究、交易、风控之间保持上下文不断裂。
- 连续使用 3 小时不疲劳，持续使用 30 天仍然可信。
- 让 AI Agent 加速投研、筛选、解释和监控，但关键交易与策略变更始终经过明确审批。

Ditto 不是商业 SaaS、不是内容门户、不是聊天产品，也不是把大量能力平铺出来的功能目录。它是围绕专业判断和闭环执行组织的内部工作台。

## Brand Personality

Ditto 的品牌人格是：克制、可信、敏锐。

语气应像一个冷静的专业同事：直接、准确、有边界感。界面不讨好用户，不制造情绪噪声，不用营销语言包装能力。它应该让用户感到系统可靠、信息有秩序、风险被正视、行动路径清楚。

合适的参考气质：

- Bloomberg Terminal 的专业终端感，但不做表皮模仿。
- TradingView 的图表交互密度，但避免社交和内容化气质。
- VS Code 的工作台结构和可记忆布局。
- Linear、Vercel、Raycast 的克制、灰阶秩序和交互清晰度。
- Quant desk 的长期工作环境，而不是一次性演示大屏。

AI 在 Ditto 中不是独立人格，也不是聊天入口。AI 更像研究助手、任务执行者、审批请求方和产物生成器，必须服从同一套工作台语法。

## Anti-references

Ditto 明确不应看起来像：

- 普通 SaaS 后台：大卡片、营销式首页、空泛指标、低密度装饰。
- AI 聊天壳：中心是对话框，业务产物被聊天记录吞没。
- 金融大屏：霓虹、发光、地图、炫技动效、满屏状态色。
- 卡片墙：同尺寸卡片堆叠，图标加标题加描述重复铺满页面。
- Bloomberg 表皮模仿：黑底高饱和文本、拥挤命令码、复古终端噪声。
- 功能超市：导航和入口压过当前工作，用户先看到功能目录而不是当前上下文。
- AI coding 廉价 UI：模板化渐变、玻璃拟态、无意义发光、没有金融语义的彩色标签。

## Design Principles

1. 判断先于操作，操作先于美感。
   所有界面决策先问是否帮助用户更快识别状态、形成判断、减少误读。美感应从效率和秩序中长出来。

2. 闭环不能断。
   市场、研究、回测、信号、订单、风险和改进必须通过上下文连续连接。跨域跳转要携带对象、原因、状态和下一步动作。

3. 导航退后，上下文靠前。
   用户进入页面后，应先理解当前工作对象、数据新鲜度、关键风险和主工作面，再理解可以去哪里。

4. 高密度必须可持续。
   信息密度是生产力，但密度必须由层级、对齐、稳定位置和渐进披露支撑。不能用拥挤、缩小文字或彩色噪声换取表面上的信息量。

5. AI 融入工作流，关键行动有门控。
   Agent 输出必须进入 Strategy Studio、Signals Inbox、Research、Platform 等业务工作流。涉及交易、策略配置、回测启用和危险操作时，审批必须清楚、可追溯、不可混入普通对话文本。

## Accessibility & Inclusion

默认目标为 WCAG AA。Ditto 是高密度专业工具，但不能以牺牲可读性、可辨识性和键盘可达性为代价。

关键要求：

- 色盲友好：重要状态至少使用两种表达维度，例如颜色加文本、图标、位置、字重、形状或线型。
- Reduced motion：所有非必要动效应可降级，运行反馈不能只依赖动画。
- 键盘可达：表格、队列、抽屉、侧栏、命令入口、审批动作都应可通过键盘定位和操作。
- 金融风险清晰：危险操作、交易确认、Agent 审批、数据 stale、系统故障必须使用明确文案和稳定位置表达。
- 中文优先，英文术语克制使用：金融与量化术语可以保留英文缩写，但界面判断语句应优先清楚可读。
