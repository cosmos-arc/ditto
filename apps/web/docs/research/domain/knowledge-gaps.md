## 2. 数据源约束

### 2.1 当前数据源

| 数据源 | 数据类型 | 频率 | 延迟 | 限制 | 可靠性 |
|--------|---------|------|------|------|--------|
| **tushare** | OHLCV、复权因子、涨跌停、停牌、财务、指数、北向、龙虎榜、融资融券、公司行动 | 日线 | T+1 ~16:00 | 200 次/分（10K+ 积分） | 中高 |
| **MiniQMT (xtquant)** | Level-1 实时行情、订单执行、持仓查询 | 3s tick | ≤3s | QMT 客户端需保持登录 | 中 |
| **通达信** | 历史 1min/5min（本地缓存 1-3 年）、日线交叉验证 | 日线/分钟 | 本地 | 需手动同步 | 高（本地数据） |
| **FRED** | 宏观指标（USD、利率、CPI、黄金、原油） | 日/月 | T+1d | 120 次/分 | 高 |

### 2.2 数据缺口

| 缺口 | 影响 | 可能的数据源 |
|------|------|-------------|
| 分钟级历史数据 | tushare 10K 档不提供分钟 K，影响日内策略回测 | 通达信本地缓存 / 聚宽付费 / AKShare |
| 实时新闻流 | 当前无实时新闻数据接入 | AkShare 新闻 / Tavily / 自建爬虫 |
| 社交舆情 | 无舆情数据 | Stock Sentiment API（Reddit/X，仅美股）/ 新浪微博（A 股） |
| 期权数据 | 无期权链数据 | tushare（付费）/ 通达信 |
| 基金持仓 | 无公募基金持仓数据 | tushare 基金数据 / 天天基金 |

### 2.3 数据质量风险

| 风险 | 数据源 | 影响 | 缓解措施 |
|------|--------|------|---------|
| tushare 积分降级 | tushare | API 调用次数减少，数据延迟增加 | 多数据源交叉验证 + 本地缓存 |
| QMT 客户端断连 | MiniQMT | 实时行情中断 + 无法下单 | 断线重连 + 本地缓存 + 告警 |
| 复权因子更新延迟 | tushare | 除权除息日 K 线数据不一致 | 盘后自动更新 + 手动校验入口 |
| FRED 数据延迟 | FRED | 宏观指标更新滞后 | 多源对比（Wind/Choice） |
