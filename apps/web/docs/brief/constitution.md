# Ditto Constitution

> 2026-11-08 按[日用上线决议](https://github.com/cosmos-arc/ditto/issues/729#issuecomment-6720456379)校正。
> 本文件记录与 [PRODUCT.md](../../PRODUCT.md)相容的产品和安全约束；机器约束及根/近端 AGENTS 定义工程规则，不新增独立审批或发布门。

## 技术与数据约束 (T)

| ID | 约束 | 说明 |
| --- | --- | --- |
| T1 | 沿现有数据边界接入 | 复用已有数据源、适配器与消费者，数据可用性按具体范围和用途验证，不因目录存在而宣称全部可用。 |
| T2 | 不连接券商交易 | 不依赖 MiniQMT/xtquant 执行交易，不提交、修改或撤销真实订单，不托管券商凭据；市场数据接入保持只读。 |
| T3 | 时效按用途表达 | 以数据实际频率、最近完整交易日、公告/观察时点和既有更新承诺判断过期与缺失；日频、财务、宏观数据不套用统一 tick 秒数或延迟阈值。盘后研究的信息截止与允许执行时间继续分离。 |
| T4 | 前端 SPA | 使用当前 Web/API 架构与同提交契约身份，不为本版另建 SSR/RSC 或 SEO 能力。 |
| T5 | 复用设计 tokens | 静态颜色、密度、字体与布局值沿现有 tokens 和工程规则维护，不在页面另设冲突体系。 |
| T6 | 设计方案需验证 | 现有 token 分层和组件可复用；五域与 Graphite Studio 只是 [信息架构裁定](https://github.com/cosmos-arc/ditto/issues/730)与[交互与视觉原型验证](https://github.com/cosmos-arc/ditto/issues/731) 的候选，不将历史布局当作不可修改的产品约束。 |

## 产品边界 (P)

| ID | 约束 | 说明 |
| --- | --- | --- |
| P1 | 个人本地工作站 | 默认单个本地操作者，不承诺多用户、团队权限、多租户或商业 SaaS。 |
| P2 | 业务任务为主 | 产品 Agent、ML 和自由 Python 工作台新增能力后置，传统研究不依赖聊天或 Agent；保留已有权限隔离与成果。 |
| P3 | 主要工作面明确 | 表格、图表、账户记录和研究结果服务当前任务，避免无关卡片与功能目录挤占工作区。 |
| P4 | 非内容产品 | 不以内容运营、社交或 SEO 为本版目标。 |
| P5 | 视觉语言一致 | 沿现有品牌与 tokens 保持克制、可信、可读；最终信息架构和视觉基线由 [信息架构裁定](https://github.com/cosmos-arc/ditto/issues/730)与[交互与视觉原型验证](https://github.com/cosmos-arc/ditto/issues/731) 验证，不在本文件预先签收。 |

## UX 原则 (U)

| ID | 原则 | 说明 |
| --- | --- | --- |
| U1 | 长期可用 | 先逐任务验收，维护者连续日用周期之后确定；不将旧的固定使用时长当成已批准验收门。 |
| U2 | 状态正确、行动可控 | 用户能理解当前对象、结果、风险与下一步；操作承诺与实际保存、执行和恢复结果一致。 |
| U3 | 视觉品质可核查 | 维护者看真实工作面认可；自动截图和源码标记不能代替设计判断。 |
| U4 | 市场色一致 | 沿现有 A 股红涨绿跌及适用偏好统一表达，避免市场涨跌与任务成功/失败混用。 |
| U5 | 色盲友好与可达 | 重要信息至少两个表达维度；保持可读字号、键盘可达、焦点和必要动效降级。 |
| U6 | 任务上下文连续 | 系统维护对象、日期、来源、策略版本和账户身份；普通路径不要求手填内部 ID/hash/协议 JSON 或开发者救援。 |
| U7 | 渐进披露 | 主要判断与操作在工作面，完整来源身份和诊断按需展开；不通过缩小文字换取密度。 |
| U8 | 状态与恢复有效 | 按任务覆盖正常、空、过期/缺失、运行中、失败/阻断与必要恢复；说明影响范围及可执行的下一步。 |

## 正确性与安全 (C)

| ID | 约束 | 说明 |
| --- | --- | --- |
| C1 | 保留既有审批隔离 | 策略/信号治理、Paper 授权与危险操作遵循现有权限和审批规则；审批明确、可追溯，不混入对话文本，不为普通研究另加审批门。 |
| C2 | 资金与账本一致 | Model、Paper、Manual 事实分离；保留账户事件、更正留痕、幂等、对账、重启及必要恢复保护。影响账户或删除记录的动作明确其后果并沿既有规则确认。 |
| C3 | PIT 与来源身份 | 信息可知时间、业务日期、版本和来源快照必须传播；必需证据缺失则拒绝对应消费，不填造状态或静默换用其他结果。 |
| C4 | 支持范围内的交易真实性 | 股票/ETF 普通研究保留费用、滑点、交易单位、适用 T+1、涨跌停、停牌/ST/退市与公司行动现金/份额语义，按标的和区间验证，不以一般免责声明替代必需实现。 |
| C5 | 用途与资格分开 | 普通回测完成不自动取得严格历史、信号或 Paper 资格；Manual 与 Paper 分别验收，技术检查和数据连续运行不能替代真人日用。 |

完整备份/灾后恢复继续沿既有暂缓决定；现有数据、Paper 和实际发布形态的安全门保留，不因本次文档校正扩大验收范围。当前版本安排统一在[产品上线地图](https://github.com/cosmos-arc/ditto/issues/726)维护。
