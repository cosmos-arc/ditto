## 技术约束 (T)

| ID | 约束 | 说明 | 确定性 |
|----|------|------|--------|
| T1 | 可插拔数据源架构 | 数据层独立解耦，适配器模式接入，支持运行时注册/替换 | 高 |
| T2 | MiniQMT 交易依赖 | 实盘交易通过 xtquant SDK 执行，QMT 客户端需保持登录状态 | 高 |
| T3 | WebSocket 实时推送 | 交易时段 3 秒级 tick 数据推送，延迟 <10s 为 stale | 高 |
| T4 | 前端 SPA 架构 | 无 SSR/RSC，量化研究工具无 SEO 需求 | 当前选择，可调整 |
| T5 | 色彩空间 OKLCH | 所有颜色值使用 OKLCH，禁止 HEX/RGB/RGBA | 当前选择，可调整 |
| T6 | 9 层 Token 体系 | Foundation → Semantic → Shell → Data View → Component → Interaction → Domain Semantic → Density → Module Pattern | 当前选择，可调整 |

## 产品边界 (P)

| ID | 约束 | 说明 |
|----|------|------|
| P1 | 非多租户 SaaS | 内部量化平台，支持多用户但不做独立部署/商业化 |
| P2 | 非 AI Chat UI | AI Agent 不走对话产品 UI，输出直接流入工作流（Strategy Studio/Signals Inbox） |
| P3 | 非卡片墙布局 | 工作站由 workspace/panel/table/chart/queue/editor 组成，非散落卡片 |
| P4 | 非 SEO/内容产品 | 无搜索引擎优化需求，无内容运营功能 |
| P5 | 单一品牌色 | Lapis Blue（hue 235°），禁止多彩品牌色系统 |

## UX 原则 (U)

| ID | 原则 | 说明 |
|----|------|------|
| U1 | 长期可用性优先 | 3 小时连续使用不疲劳，30 天持续使用仍可信 |
| U2 | 专业感来自控制 | 判断速度 > 操作速度 > 长期使用 > 美观度 |
| U3 | 独特品味 | 脱离 AI coding 廉价 UI 感，交互/可视化/清晰度有独特突破 |
| U4 | 市场色规范 | A 股红涨绿跌（默认）+ 国际色可切换，全局实时生效 |
| U5 | 色盲友好 | 所有重要信息至少两个表达维度，不依赖单一颜色传达 |
| U6 | 5 秒原则 | 用户进入任意页面 5 秒内回答关键问题 |
| U7 | L1/L2/L3 信息层级 | 零导航成本（可见）/ 滚动成本（可折叠）/ 一键（按需展开） |
| U8 | 导航退隐 | 导航退到背景，工作区前置。用户先理解当前工作，再理解去向 |

## 合规与安全 (C)

| ID | 约束 | 说明 |
|----|------|------|
| C1 | AI 审批门控 | Agent 涉及交易/策略配置/回测的操作需人工审批，审批不可混入对话文本 |
| C2 | 危险操作确认 | 暂停交易/全部撤单/停止 Agent 等操作需明确风险语义 + 确认弹窗 |
| C3 | 域分离色语义 | 7 个业务域（Market/Risk/Execution/System/Data/Model/Agent）色语义不可交叉污染 |
| C4 | A 股规则引擎 | T+1、涨跌停、停牌、最低交易单位、印花税等 A 股规则内置，非外挂 |
