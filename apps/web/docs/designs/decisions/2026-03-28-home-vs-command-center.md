# Home vs Command Center 分家决策

> **核心原则：Home 是雷达，Command Center 是驾驶舱。**
>
> Home 的核心动词是 **orient**（理解 → 分流）。
> Command Center 的核心动词是 **execute**（判断 → 执行）。

---

## 1. 页面角色定义

| | **Home（全域首页）** | **Command Center（交易指挥中心）** |
|---|---|---|
| 核心动词 | orient（理解 → 分流） | execute（判断 → 执行） |
| 用户心智 | "今天怎么样？去哪？" | "做什么？先做哪个？" |
| 主工作面 | 今日优先事项（跨域 3-5 条） | 执行队列（交易域，7+ 条） |
| CTA 语气 | 导航型（查看 / 进入 / 打开） | 操作型（执行 / 复核 / 确认） |
| 市场信息 | 前置、轻量（脉搏式） | 详细、嵌入判断 |
| 底部内容 | 研究进展 + Agent 洞察（全域） | 信号流 + 交易洞察（交易域） |
| 信息密度 | 预览级（queue preview） | 操作级（action workspace） |

---

## 2. 内容准入规则

### 三层分类

| 分类 | 含义 | 规则 |
|---|---|---|
| **专属** | 只在一个页面出现 | 不允许跨页出现 |
| **共有但异构** | 两个页面都有，但形态/深度不同 | 必须明确区分展示层级 |
| **共享组件** | 结构一致，数据源相同 | 可复用，但权重/位置不同 |

### 准入判断法

给任何新模块决定归属时，问一个问题：

> **这个模块的核心动词是 orient 还是 execute？**

- orient → Home
- execute → Command Center
- 两者都有 → 放两边，但 Home 用预览级，CC 用操作级

| 模块 | Home | Command Center | 分类 | 说明 |
|---|---|---|---|---|
| **研究进展** | ✅ 底部左栏（主） | ❌ | 专属 Home | CC 不承载研究流 |
| **市场脉搏** | ✅ 右 rail 顶部 | ❌ | 专属 Home | CC 内嵌在判断区，不需要独立面板 |
| **今日优先事项** | ✅ 主工作面 | ❌ | 专属 Home | CC 用执行队列替代 |

| **Agent 洞察** | ✅ 底部右栏（全域） | ✅ 底部右栏（交易域） | 共有但异构 | Home: 跨域（市场/风险/研究/数据）；CC: 聚焦交易信号 |

### Home 阅读顺序

1. 组合状态 — 今天整体怎么样
2. 市场判断 — 系统对当前环境的结论
3. 分流 CTA — 去哪里
4. 今日优先事项 — 最该关注什么（跨域）
5. 市场脉搏 / 全局预警 / 数据健康 — 环境是否允许安心工作
6. 研究进展 + Agent 洞察 — 系统近期在研究和平台层面发生了什么

## 4. 各区块设计要点

### Status Banner

- **左（组合状态）**：总权益 / 日 PnL / 较昨日变化。摘要级，不放仓位/杠杆细节。
- **中（市场判断）**：一句 Regime 判断 + 1-2 个支撑指标（如 IVIX、北向）。是"结论入口"，不是"指标面板"。
- **右（分流 CTA）**：3 个导航入口，如"查看信号总览" / "进入研究工作台" / "打开风控中心"。不催用户在首页干活，引导去对应工作区。

### 今日优先事项

- 取代执行队列成为 Home 主工作面
- 内容跨域：交易执行、研究提醒、数据异常、风险事件
- 只展示 3-5 条，更多通过"查看全部"进入对应域
- 行内操作弱化：不露"执行/复核/静默"，改为"查看详情" / "进入处理"
- 语气：系统帮你排了今天最值得关注的几件事，不是请在这里干活

### 右 Rail

- **市场脉搏**（顶部，专属 Home）：4 个关键指标，极轻，每项一行
- **全局预警**（中部）：3-4 条单行预览
- **数据健康**（底部）：preview 摘要

### 底部双栏

- **左：研究进展**（专属 Home）：回测结果、研究任务、模型/因子更新、待复核结论
- **右：Agent 洞察**（共有但异构）：跨域洞察，涵盖市场/风险/研究/数据

### 关键差异对照

| 维度 | Home | Command Center |
|---|---|---|
| Banner 右 | 分流 CTA（导航） | 执行 CTA（操作） |
| 主工作面 | 今日优先事项（跨域） | 执行队列（交易域） |
| 右 rail 顶部 | 市场脉搏 | 全局预警 |
| 底部左 | 研究进展 | 信号流 |
| 底部右 | Agent 洞察（全域） | Agent 洞察（交易域） |
| 操作深度 | 预览级 | 操作级 |
