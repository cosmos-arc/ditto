# Ditto 产品设计方案 — 全市场全资产量化平台

## Context

Ditto 定位为**全市场全资产量化平台**，目前主要聚焦 A 股市场，但页面设计与数据模型均按通用扩展原则构建，支持未来覆盖港股、美股、期货、期权等市场。

后端 API 已具备数据查询、回测执行、因子分析、Regime 分析等能力。前端产品覆盖**研究、交易、市场情报、AI 辅助、平台运维**五大工作域，形成从数据采集 → 因子研究 → 策略构建 → 回测验证 → 实盘交易 → 风控监控 → AI 辅助决策的完整闭环。

**技术选型**：Vite + React + TypeScript + shadcn/ui + Tailwind CSS v4 + TanStack Router + TanStack Query + Zustand + ECharts + TradingView Lightweight Charts
**包管理**：bun
**设计系统**：Design Token 架构（详见 [Design Token 架构设计](./2026-03-26-ditto-app-design-token-v2.md)）
**页面视觉原则**：详见 [页面视觉原则](./2026-03-26-ditto-visual-principles.md)

## 1. 产品定位与设计原则

### 1.1 业界对标

| Ditto 功能模块 | 最佳参考平台 | 核心参考点 |
|---------------|------------|-----------|
| 回测结果 UI | **QuantConnect LEAN** | 9 内置图表 + 20+ 统计指标 + 多 Tab |
| 因子研究 | **RiceQuant RQFactor + JoinQuant jqfactor** | IC/IR 衰减曲线、分层回测 |
| 组合管理 | **Bloomberg PORT + TWS Risk Navigator** | 钻取层级、What-If 分析 |
| 风控监控 | **TWS Risk Dashboard + Bloomberg PORT** | VaR 实时监控、暴露限制仪表盘 |
| 市场情报 | **Bloomberg Terminal + Wind** | 资金流、新闻聚合、关联网络 |
| 策略管理 | **QuantConnect Project Management** | 版本管理、状态标签、克隆/归档 |
| AI 辅助 | **ChatGPT + Perplexity** | 对话式交互、结构化输出 |
| Agent 工作台 | **AutoGPT + CrewAI** | Plan → Run → Find → Approve 流程 |
| 图表交互 | **TradingView + QuantConnect** | 十字线、缩放同步、多面板联动 |
| ML 平台 | **Weights & Biases + MLflow** | Experiment tracking、Model Registry、Drift Monitoring |

### 1.2 关键设计原则

- **暗色主题默认**：所有量化平台标配，A 股红涨绿跌
- **模块化面板布局**：可拖拽/调整大小的 Dashboard
- **2 秒评估原则**：P&L 和持仓状态始终可见，一眼判断好坏
- **钻取层级**：组合 → 行业 → 标的 → 交易 → 指标
- **跨图表时间同步**：缩放一个图表，所有图表联动
- **可导出报告**：HTML/PDF 一键生成
- **AI-First 思维**：每个工作域都预留 AI 辅助入口，但不喧宾夺主

> **完整的视觉设计体系**（12 条量化专业视觉原则）详见 [Ditto 视觉设计原则](./2026-03-26-ditto-visual-principles.md)。

## 2. 全站统一设计约定

> 以下规则贯穿全站所有页面，确保页面再扩也不会散。

### 2.1 页面类型与默认布局

| 页面类型 | 布局模式 | 适用场景 |
|----------|----------|----------|
| **列表页** | 左筛选 / 中主表 / 右预览（或顶筛选 / 中主表 / 右预览） | 资产目录、标的池、策略目录、因子库、回测列表、信号中心、订单管理、告警中心等 |
| **对象页** | 顶标题 + KPI/状态 + tab 导航 + 主图区 + 细节区 | 资产详情、回测结果、实验详情、因子分析、策略 Hub 等 |
| **工具页** | 自定义专业布局（编辑器 / 图表工作台 / 对话式） | Chart Lab、Strategy Editor、AI 市场分析、研究 Copilot 等 |
| **总览页** | KPI 横排 + 核心面板 + 摘要列表 | 首页总览、各域 Overview 页 |

### 2.2 交互约定

| 约定 | 规则 |
|------|------|
| **对象详情页入口** | 不做常驻菜单，只通过列表、图表、告警、搜索、卡片下钻进入（URL 路由存在，侧边栏不显示） |
| **列表行点击** | 单击 → 高亮并在右侧预览；双击或主 CTA → 进入对象详情 |
| **主 CTA 数量** | 每页最多 1-3 个主 CTA，避免选择困难 |
| **页面骨架四层** | 页面标题层 → 筛选控制层 → 核心内容层 → 辅助信息层（详见页面出图指导原则） |

### 2.3 页面分类标注

本文档中对每个页面标注来源：
- **沿用现有稿**：基于已有设计骨架做延展升级
- **新增**：本版产品设计新增的页面

## 4. 页面功能规格

### 4.1 Home — 首页

#### 4.1.1 首页总览 `/` 【沿用现有稿并升级】

**定位**：合并后的控制中心横幅 + 任务枢纽 + 可配置工作台

**核心区块**：
- **上方**：控制中心横幅 — 今日 PnL / 收益率 / 总资产 / 决策辅助（沿用现有骨架）
- **中间**：2×2 面板 — 风险摘要、市场环境快照、待处理事项、快捷操作

**默认 tab**：不设二级 tab，首页即总览

**主要 CTA**：
1. 查看信号
2. 新建订单复核
3. 进入研究台
4. 打开回测中心
5. 编辑我的工作台

**跳转关系**：
| 入口 | 目标 |
|------|------|
| 待处理事项 | Portfolio & Trading > 信号中心 / 订单管理 / 告警中心 |
