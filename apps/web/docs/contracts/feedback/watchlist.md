# Watchlist contract feedback

- Retained the catalog toolbar, list surface, and evidence rail.
- Add/remove is functional for positive numeric instrument IDs and display fields always resolve from the public metadata catalog.
- Persistence is deliberately local to the current browser and is labeled as such; no cloud sync or server write is implied.
- Real-time price, signal, news, exposure, bulk-write, and workflow overlays were omitted because no stable public contracts exist.
- The add-by-ID toolbar uses a readable two-row layout; its reviewed height difference and the corresponding list/detail offset are explicit in the visual contract.
