# Prototype Best UI/UX Optimization Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 将 Ditto 原型从“工程化成熟的高保真原型”推进到“可对标 Bloomberg / TradingView / Linear / Raycast 的专家工作台体验”，优先修复当前验收阻断、版本歧义和专家效率闭环。

**Architecture:** 采用两层推进：先修会阻断 `bun run check`、Edition 收敛和共享设计系统一致性的基础问题；再补 Command action bus、交互式图表、工作台记忆、Trading Overview 信息架构等产品级能力。原型层继续保持零 inline style、共享 CSS/JS、三区结构和机器可读合同；React 落地能力通过 contract/test 先定义，避免原型变成一次性展示稿。

**Tech Stack:** HTML prototypes, shared prototype CSS/JS, Design Tokens, Bun, Vitest, JSDOM, Playwright, `lightweight-charts` for React chart implementation planning.
