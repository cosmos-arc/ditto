# Web quality evidence

Evaluate these Web-specific signals within the fixed quality dimensions:

- strict TypeScript across browser, unit, Playwright and tooling projects;
- alias-aware graph cycles, feature deep imports, route public APIs and shared
  reverse dependencies;
- typed OpenAPI transport and isolation of generated DTOs behind adapters;
- unit retry policy, global and high-risk branch coverage, and meaningful
  loading/empty/error/stale tests;
- design-token enforcement in CSS/TS, light/dark contrast, canonical prototype
  link integrity and critical/serious axe results;
- route-level splitting, raw/gzip budgets, initial CSS and font transfer budget;
- runtime config validation, strict mock behavior and production-mode E2E.

Use current machine output and source paths. Historical prototype screenshots,
coverage HTML and acceptance JSON are not proof of the current commit.
